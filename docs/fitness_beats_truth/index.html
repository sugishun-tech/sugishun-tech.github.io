1. 情報量ではなく、意思決定則を比べる

P(w | x) = μ(w) P(x | w) / Σᵥ μ(v) P(x | v)
Truth: S_T(x) = f(argmax_w P(w | x))
Fitness-only: S_F(x) = Σ_w P(w | x) f(w)
Hybrid: S_H(x) = α S_T(x) + (1 − α) S_F(x)

「真実を知るあらゆる知性」と「無知」を競わせたものではありません。Truth はMAP点推定に縮約する特定の戦略です。事後分布全体を保ち期待利得を計算する、現実を重視した推論も同じ選択をできます。感覚ノイズ・解像度は両戦略に共通です。MAP同率時は最小の状態番号を採用し、行動評価が同率なら資源間で等確率に選びます。

2. 資源ゲームと実際の個体群更新

正の出現確率を持つ各信号の資源を1個ずつ提示します。先手は等確率。先手が最も高く評価する資源を取り、後手は残りから選びます。事後分布と同率選択を厳密に平均し、対戦利得行列 A を作ります。実現した食事の得点ではなく、期待利得が出生重みを決めます。独占をOFFにすると、双方が独立に資源を選ぶ拡張になります。

πᵢ = Σⱼ (nⱼ − 1{i=j}) Aᵢⱼ / (N − 1)
bᵢ = max(0, 1 − s + s (πᵢ − cᵢ))
P(parent type=i) = nᵢ bᵢ / Σⱼ nⱼ bⱼ
P(death type=j) = nⱼ / N

式は存在する戦略についてのものです。個体数0の戦略は出生確率0で、表示用の反実仮想利得のみN個体を対戦相手として平均します。出生と死亡は独立に選びます。子は原則として親の戦略を継ぎ、設定確率で別の有効戦略へ変異します。重みが全て0なら一様な出生に戻します。突然変異・戦略別費用・Hybrid・人為的再導入は本アプリの拡張です。標準の費用は全て0。座標、移動速度、見た目、音はこの計算に参加しません。

3. 数値例の照合

初期シナリオでは E[f|x₁]=5、E[f|x₂]=6.6、MAPによる評価はそれぞれ4、3です。資源を独占する二者ゲームの期待利得は F対F=5.8、F対T=6.6、T対F=5、T対T=5.8。これは付録の数値から本アプリが計算した行列です。最大の実現利得20を得られるかは、その1回の幸運に左右されます。

4. 結論の限界

完全情報では二戦略の評価が一致します。同じ利得でも有限集団は遺伝的浮動で固定し得ます。さらにFに十分な費用を課せばTが有利にもなります。固定環境・既知の確率と適応度という仮定があり、学習過程はモデル化していません。環境反転では両者が変更後の適応度を即座に利用します。空間的な生態系や人間の視覚の実測モデルではなく、外界の不存在、意識の根源性、科学的知識の無効を実証するものでもありません。

FBT定理の一般的な確率主張を、この有限の一環境に無条件で当てはめません。ここでは数値例、意思決定則、明示した集団更新だけを検証可能な形で実装しています。

実験室の使い方
最初は「開始」を押すだけ。 緑の丸Fと桃色の三角Tが同じ情報から資源を選び、その期待利得に応じて子孫を残します。光の軌跡は、実際に選ばれた出生と置換です。一定数の個体が入れ替わり続けます。
観察 → 介入 → 対照 → 反復
「知覚を解剖」で、なぜ両者の選択が違うのか確認。「環境を反転」で適応度を並べ替え、「少数派を再導入」で絶滅後も実験に介入できます。いずれもログに記録される外部操作です。設定のシナリオ03は完全情報、04は選択なしの対照実験です。
「自分で選ぶ」では標準12問の採餌ゲーム（問題数は変更可能）。「反復実験」では同じ設定を別の乱数種で繰り返し、1回の幸運と統計的傾向を分けられます。設定とCSVはブラウザから保存できます。

すべてのパラメータ
任意の μ・P(x|w)・f(w) を使うには model="custom" にし、customWorld を編集します。確率は非負で行和1、適応度は非負。未知のキー、不正な世界データ、範囲外はエラーにします。省略した設定キーにはデフォルト値を補います。ここで反映後、実験への適用は左の「設定を適用して開始」です。


設定を共有
現在の環境と実行設定をURL末尾に格納します。集団の途中状態・介入履歴は含みません。ローカルファイルのURLは他の端末では開けないため、GitHub Pagesで共有するか「設定保存」を使ってください。
