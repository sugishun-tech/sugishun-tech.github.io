# 信念の共和国 / BELIEF REPUBLIC

**モデル版: `3.3-endogenous-interests`**。25シナリオ・26種類の介入・115パラメータ。給付から受益組織が育ち、広告・動員・移転削減への抵抗を通じて選挙と次の政策へ戻る経路を追加しました。実施から組織化までのラグ、停止後の減衰、監査・一般ルール・財源負担もモデル化。詳細と検査は第36節です。

経済に関する知識・誤認・期待・党派性・ネットワーク・投票・政策・景気・分配が相互作用し、**信念が票になり、政策が経済を変え、その結果が再び信念へ戻る**過程を観察するエージェントベースの社会シミュレーションです。

このプロジェクトは `index.html` だけで実行できます。ビルド、サーバー、外部JavaScriptライブラリ、外部APIは不要です。GitHub Pagesにもそのまま置けます。

> **重要**
>
> これは現実社会の予測装置でも、特定政党の勝利を証明する装置でもありません。  
> 未較正の仮定を意図的に可視化し、「どの条件を変えると、どのような政治経済ダイナミクスが生じるか」を調べるための実験室です。

## 1. 何をシミュレーションしているのか

各市民は、単なる「右か左か」の1変数ではありません。少なくとも次の状態を持ちます。

- **政策選好 `b ∈ [-1, 1]`**
  - `b > 0`: 規則派 R 寄り
  - `b < 0`: 裁量派 D 寄り
  - `|b|` が小さい: 留保・中間
- **事実認識 `z ∈ [-1, 1]`**
  - 貨幣拡張が長期に残す実質効果についての符号付き推定
  - 世界側の「真値」は `θ = longReal`
- **知識量 `k ∈ [0, 1]`**
  - 情報へ接触し、処理する能力の代理
- **確信度 `c ∈ [0, 1]`**
  - 高いほど新情報で動きにくい
- **党派アイデンティティ**
- **所得・稼得能力**
- **移転受益順位**
- **過去の政策経験**
- **情報ネットワーク**
- **直近の投票行動**

ここで最も重要なのは、**事実認識と政策選好を同一視していない**ことです。

たとえば `z` が世界の真値 `θ` に近くても、自己利益、時間選好、移転の受益、価値判断などが異なれば、同じ政策を支持するとは限りません。逆に、知識量が多くても認識が正しいとは限りません。

## 2. R と D は何を意味するのか

この作品では二つの仮想的な政治陣営を置きます。

### 規則派 R

- 貨幣供給を基準ルール `μ₀` に近く保つ
- 裁量的な追加拡張を原則として行わない
- 追加移転が小さい
- 継続的なルール遵守によって「規則への信頼」が回復しうる

### 裁量派 D

- 景気・失業・選挙時期に応じて `μ₀` を超える追加的な貨幣拡張を行いうる
- 追加移転を行う
- 選挙が近いほど、再選志向に応じて刺激を強めうる
- 裁量的な逸脱や政策急変は「規則への信頼」低下や「政策不確実性」を生みうる

**R = 真、D = 偽というラベルではありません。**

世界の真値 `θ` は独立したパラメータです。既定値は `θ = 0` ですが、`θ > 0` や `θ < 0` に変更できます。

## 3. 既定の経済世界

既定設定は、フリードマン的な短期・長期の区別を強く意識した縮約モデルです。

- 長期の恒常的実質効果: `θ = 0`
- 供給価格要因を除く金融サプライズは一時的に産出ギャップへ作用
- 期待が追いつけば、同じ裁量刺激の短期的な実質効果は消耗
- ルールへの信頼が高い規則型政策は期待を基準インフレへ再アンカーしうる
- 裁量的な急変は政策不確実性を増やしうる
- 政策にはラグがある
- 供給ショックと実物景気ショックは金融政策と別に存在する

モデルは完全なDSGE、貨幣需要モデル、金融仲介モデルではありません。**政治学習と期待形成をゲームとして観察するための縮約モデル**です。

## 4. 1四半期に何が起きるか

1期は1四半期です。実装上は外生乱数を先に取得しますが、期待の計算関数には前期の状態と既知の適用政策だけを使い、当期の新しい攪乱は参照しません。

```text
前期のマクロ状態を保存
    ↓
外生ショック、前期に予約した介入を生成
    ↓
政策決定 → キュー → ラグ後の政策を適用
    ↓
前期までの情報から、当期の期待を固定
    ↓
金融トレンド・総インフレを実現
    ↓
金融サプライズと供給要因を分けて産出・失業を計算
    ↓
家計・学習・政策評価 → 選挙 → 指標・診断を保存
```

政策決定と経済結果の間にラグがあるため、**現在の政権と、現在観測されている経済結果を生んだ政権が一致しない**ことがあります。

その帰属を正しく行える確率が `attribution` です。

## 5. 中核となる経済ダイナミクス（v2.0の骨格＋v3.2の信用負担）

本編の `Republic.step()` と統制実験は、同じ純粋関数 `advanceMacro(before, parameters, appliedPolicy, shocks)` を呼びます。図だけに別の計算式を使って「それらしい曲線」を描く設計ではありません。

以下の数式は安全上限が作用していない範囲です。係数は未較正です。期待を加えたフィリップス曲線という出発点と、ゲーム独自の分解・係数は区別してください。文献は第30節にあります。

### 5.1 裁量と政策ラグ

```text
d = 1{裁量派政権} × (1 − 実効裁量制約)

μ[t] = μ₀ + d × [
    stimulus × (0.25 + 0.75 × reelection × election_phase³)
  + 0.4 × max(u[t−1] − u*, 0)
]
```

`election_phase` は選挙直後の0から次の選挙の1へ進みます。決定した政策はキューに入り、`policyLag = L` 四半期後に適用されます。失業への反応項の基準は従来どおり基礎自然率 `u*` です。

### 5.2 金融トレンドと供給価格圧力を分ける

```text
πᴹ[t] = πᴹ[t−1] + κ × (μ[t−L] − g − πᴹ[t−1])
S[t]  = 0.58 × S[t−1] + 供給イノベーション[t]
π[t]  = πᴹ[t] + S[t]
```

`πᴹ` はこのモデル内の金融トレンド成分です。統計上の「コアCPI」と同じ意味ではありません。`S` は一過性の供給価格圧力です。単発の供給危機を、恒常的な貨幣増加率の上昇と同一視しません。

以前の実装では、供給要因を含んだ総インフレの予想誤差に景気押上げ係数を掛けていました。v2.0ではその経路を分離し、供給危機の価格上昇を金融刺激の便益として加点しません。

### 5.3 当期の実現値を見ずに期待を形成する

適応的期待の金融成分をまず次のように計算します。

```text
E_raw[t] = Eᴹ[t−1]
         + λ × (πᴹ[t−1] − Eᴹ[t−1])
         + χ × (πᴹ[t−1] − πᴹ[t−2])

w[t]  = ruleReanchor × 前期の規則信頼 × 実際のルール遵守度
Eᴹ[t] = (1 − w[t]) × E_raw[t] + w[t] × (μ₀ − g)
```

`λ = expectationGain`、`χ = expectationExtrapolation` です。当期の実現物価や新しい外生ショックを先読みしません。再アンカーは凸結合なので、学習係数と再アンカー係数を単純に足したことによる過剰調整を避けます。ただし外挿を極端に大きくした場合の振動は意図的に残しています。

**実際の貨幣増加率が基準ルールから外れている間は、基準インフレへの再アンカーを止めます。** 一部に裁量制約があるだけで、何十年も実現値より低い期待へ強制固定され、金融拡張の実質効果が永久に残ることを防ぐためです。数値上は `|μ適用 − μ₀| < 10⁻⁹` の場合だけ、適用政策の規則度を遵守度として使います。

供給成分の期待は、固定期待モード以外では次です。

```text
Eˢ[t] = 0.58 × S[t−1]
πᵉ[t] = Eᴹ[t] + Eˢ[t]
```

期待形成には三つのモードがあります。

| モード | 金融成分の期待 | 注意 |
|---|---|---|
| `adaptive` | 前期までの情報で更新 | 既定の学習型 |
| `forward` | 既知の当期適用政策から `πᴹ[t]` を正確に予測 | 本モデルの完全情報比較。一般的な合理的期待モデルすべての主張ではない |
| `fixed` | 初期インフレに固定。供給成分の期待は0 | 期待が追いつかない比較条件。長期均衡への収束を保証しない |

### 5.4 金融サプライズ

```text
ν[t]  = S[t] − Eˢ[t]
εᴹ[t] = π[t] − πᵉ[t] − ν[t]
       = πᴹ[t] − Eᴹ[t]
```

`ν` は供給価格の予想誤差、`εᴹ` は金融トレンドの予想誤差です。この二つを混ぜません。

```text
金融による短期産出効果 = a × εᴹ[t]
裁量の短期政治利得 = 裁量強度 × a × εᴹ[t]
```

`a = phillips` です。刺激額そのものに便益を付けません。期待が追いつけば `εᴹ → 0` なので、短期便益もゼロへ近づきます。供給価格ショックだけではこの便益は発生しません。

### 5.5 実体経済と失業率

```text
rent_loss = lobby × max(適用移転率 − 2, 0) × 0.12
uncertainty_loss = policyUncertaintyAversion × 0.18 × policyUncertainty
supply_loss = supplyImpact × S[t]

gap_raw = 0.8 × θ × (μ[t−L] − μ₀)
        + a × εᴹ[t]
        + businessShock[t]
        − supply_loss
        − rent_loss
        − uncertainty_loss

u[t] = u* − 0.55 × gap[t]
```

`gap` は産出ギャップの百分率表示、`u` は失業率の%表示です。インフレは年率%。したがって `0.55` や `a` はこの単位系に対応するモデル係数であり、観測された普遍定数ではありません。

正の供給価格圧力は `supplyImpact` に応じた実物損失を伴います。負の供給ショックは逆方向です。`supplyImpact = 0` なら実物損失経路だけを切れます。

### 5.6 短期フィリップス曲線

恒常的な制度・レントの影響を含めた自然率を、次のように区別します。

```text
uⁿ = u* + 0.55 × (rent_loss − policy_supply_capacity)
β  = 0.55 × a
Ω  = 0.55 × supply_loss
   − 0.55 × businessShock
   + 0.55 × uncertainty_loss
   − 0.55 × 0.8 × θ × (μ適用 − μ₀)

u = uⁿ − β × (π − πᵉ − ν) + Ω
```

期待 `πᵉ`、供給条件 `ν`、自然率 `uⁿ`、その他の寄与 `Ω` を固定すると、`β > 0` のとき右下がりの短期関係になります。画面は横軸が失業率 `u`、縦軸がインフレ率 `π` なので、描画式は次です。

```text
π = πᵉ + ν + (uⁿ + Ω − u) / β
```

期待が上がれば短期曲線は上へ移動します。供給危機や実物条件の変化でも移動します。`a=0` の場合は `π` を `u` の関数として解けません。金融インフレが失業率を動かさない退化条件として、`u = uⁿ + Ω` の垂直な条件付き関係を描き、通常の右下がり曲線とは区別します。

### 5.6a 曲線と実現点を対応させる方法（v2.1）

描画用に実現点から切片を推定したり、点が線に乗るように失業率を移動させたりはしません。`phillipsRelation(state)` が、**保存済みの当期の期待・供給条件・実物条件・係数**から次の形を構成します。

```text
π₀,t = πᵉ_t + ν_t
u₀,t = uⁿ_t + Ω_t
U_t(π) = u₀,t − β_t(π − π₀,t)
P_t(u) = π₀,t + (u₀,t − u)/β_t     [β_t > 0]
```

`U_t` は曲線上の失業率、`P_t` は曲線上のインフレ率です。いずれも実際のマクロ式の代数的な変形です。したがって、他の条件を固定すれば `dπ/du = −1/β < 0`。`πᵉ` だけを1pt上げると `P_t(u)` はすべての `u` で1pt上がります。

画面の「線上誤差」は `実際の失業率 − U_t(実際のインフレ率)` です。安全上下限が作用していなければ、浮動小数点の丸め誤差の範囲で0になります。上下限が作用した場合は、その差が `uBounds` に一致することを別に検査します。その場合は橙色の点と警告を表示し、線形関係を満たしているようには装いません。線形の短期曲線も、有効な失業率範囲内だけ描きます。

当期の新規ショックを観測してから事前期待を書き換えることはありません。`forward` は当期の適用政策をあらかじめ知っている比較条件、`adaptive` は前期までの情報による期待です。履歴の確認中に現在のパラメータを変えても、過去の曲線には当時の期待と係数を使います。

### 5.6b 短期曲線上の移動と、曲線自体の移動

前期から当期への変化を、次の恒等式で分解します。

```text
① 曲線上の移動 = U_(t−1)(π_t) − U_(t−1)(π_(t−1))
                 = −β_(t−1) × Δπ

② 曲線自体の移動 = U_t(π_t) − U_(t−1)(π_t)

Δu = ① + ② + ΔuBounds
```

①では前期の期待・供給・制度・係数をすべて固定して、インフレだけを変えます。②では、そのインフレのもとで当期の条件に切り替えます。②は期待、供給価格、その他の実物条件、係数変更へさらに分解します。

これは**比較のための反実仮想の分解**です。同じ四半期の中でこの順序の取引が実際に観測された、という意味ではありません。図の補助矢印もこの分解を表します。実現点の履歴は点線で区別し、回帰曲線や一本の固定された短期曲線として表示しません。

### 5.6c A→B→Cの標準図と、時間経路の仮定

フィリップス曲線だけでは、インフレの時間経路は決まりません。貨幣の物価への波及式と、期待の更新式も必要です。本作品の標準図では次の統制条件を採用しています。

```text
供給・実物ショック = 0
制度・レント・不確実性の費用 = 0
θ = 0、uⁿ = 5%、β = 0.44
物価への波及 κ = 1
期待更新 πᵉ_t = πᵉ_(t−1) + λ(π_(t−1) − πᵉ_(t−1))
```

Q8で貨幣増加率を一度だけ恒久的に引き上げます。`κ=1` は、物価の波及ラグと期待の調整を分離して読むための仮定です。本編の標準パラメータをこの値へ強制変更するものではありません。

初期インフレを `π_A`、引上げ後の一定インフレを `π_C` とすると、次の経路になります。

```text
A: (u, π) = (uⁿ, π_A)、πᵉ = π_A
B: (u, π) = (uⁿ − β(π_C − π_A), π_C)、πᵉ = π_A
C∞: (u, π) = (uⁿ, π_C)、πᵉ = π_C
```

AとBは**同じ**短期曲線上です。BからC∞へは、インフレを一定に保ち、期待が上がるたびに短期曲線が上方へ移動します。Q8から `n` 期後の値は、標準実験では次の解析式とも一致します。

```text
πᵉ_(8+n) = π_C − (π_C − π_A)(1 − λ)^n
u_(8+n)  = uⁿ − β(π_C − π_A)(1 − λ)^n
π_(8+n)  = π_C
```

`0 < λ ≤ 1`、正の引上げ幅なら、失業率はBから自然率へ単調に戻ります。グラフのために最後の点を自然率へ移しているのではなく、同じ `advanceMacro` の反復計算がこの式を満たします。

「波及ラグあり」は `κ=0.4` の別実験として残しています。そこではインフレの波及と期待調整が同時進行するため、実現点の経路が標準図の折れ線と違っても、各期の短期曲線とは整合します。

### 5.7 長期フィリップス曲線

次の条件を固定します。

```text
θ = 0
金融期待と実現が一致する：εᴹ → 0
一時的な供給・実物ショックが消失
政策急変が止まり不確実性コストが消失
移転・レントなどの制度条件は一定
```

このとき、異なる一定の貨幣増加率についても、

```text
π → μ − g
u → uⁿ
```

となり、長期曲線は `u=uⁿ` の垂直線です。**インフレ率の水準を引き上げ続けても、同じ自然率の下で恒常的な失業低下は買えない**という関係です。

本編では制度条件も変わるため、自然率の位置が移動することはあります。基礎自然率 `u*` と構造調整後の `uⁿ` を隠して同じものとして扱いません。

`θ ≠ 0` の比較世界では、同じ経済式の定常状態は次です。

```text
u_LR(π) = uⁿ − 0.55 × 0.8 × θ × (π + g − μ₀)
```

その場合、画面の長期線も傾きます。垂直線を無条件に表示して理論との整合を装うことはしません。固定期待モードも、期待一致の条件が成立しない別の比較条件です。

### 5.8 なぜインフレが上がっても失業率が下がらないのか

前期比の変化と、条件を固定した曲線の傾きは別です。係数 `β` が一定なら金融要因による失業率の変化は、

```text
Δu_金融 = −β × (εᴹ[t] − εᴹ[t−1])
```

です。インフレが上がっていても、期待がもっと速く追いつけば金融サプライズは小さくなり、失業率は自然率へ戻る方向に動きます。さらに供給危機、不況、制度変更、不確実性などが相殺することもあります。

したがってv2.0も「インフレ上昇なら必ず失業低下」とはしません。修正したのは因果経路と可視化であって、すべての時系列を一本の右下がり曲線に強制する機能ではありません。

### 5.9 規則への信頼と政策不確実性

規則信頼 `policyCredibility ∈ [0,1]` は、実際に基準貨幣ルールを遵守したとき回復します。裁量による逸脱は、逸脱幅と政策変化に応じて信頼を低下させます。

```text
uncertainty[t] = 0.82 × uncertainty[t−1]
              + 0.18 × (|Δμ適用| + 0.5 × |Δルール逸脱幅|)
```

不確実性は実体経済と政策評価に作用しますが、恒久的に高いままの定数ではありません。政策が安定すれば減衰します。

### 5.10 数値安全上限

金融トレンドと総インフレは `[-12,45]`、期待の金融成分と総期待は `[-20,55]`、産出ギャップは `[-20,20]`、失業率は `[0.2,30]` に制限します。

極端な設定では線形モデルの曲線から実現点が外れます。この場合は `uBounds` に差を計上し、画面でも「上下限補正」と警告を表示します。供給価格の実現寄与・期待寄与も、上限適用後の差から計算し、`総予想誤差 = 金融予想誤差 + 供給予想誤差` の恒等式を維持します。

## 6. 「知識」と「誤認」のモデル

各市民の `z` は `[-1,1]` です。

この符号付き設計は重要です。真値 `θ = 0` のとき、無知や誤差が必ず「長期効果を過大評価する方向」にだけ出ることを避けています。

### 情報源

市民は以下から更新します。

- 近隣ネットワーク
- 検証されたメディア信号
- 党派的メディア信号
- 政策と経済結果から得た経験的信号
- 公開講座などの介入

### 確認バイアス

現在の自分の見方から遠い情報ほど受け入れにくくなります。

### 有限の受容幅

政策選好の距離が `confidenceBound` を超える相手は、通常の社会学習対象から外れます。

### 誤認の自己増幅

`misperceptionDrift > 0` では、事実認識が毎期真値から遠ざかる力が加わります。

強さは概ね、

- 知識量が低い
- 確認バイアスが強い
- すでに真値から離れている

ほど大きくなります。

## 7. 政策選好の更新

v3.3では、以下の家計・政策評価とは別に、実際の受給履歴から組織を形成します。組織による広告は党派的媒体への接触内容を変え、依存と継続期待は投票効用・参加へ作用します。追加分をDの評価へ無条件に足す処理ではありません。第36節を参照してください。

政策選好 `b` は、単純に `z` を政党ラベルへ変換しているわけではありません。

市民は概念的に、裁量派Dの純便益を次の要素から評価します。

```text
Dの知覚純便益
  = 長期便益
  + 短期便益
  - インフレ負担
  - 信頼・不確実性コスト
  - 選挙前の便乗刺激への警戒
  + 私的な移転純便益
  + 社会全体の分配評価
```

その後、

- 社会的同調
- メディア
- 過去の政策実績
- 逆張り
- 確信度
- 忘却

などが加わって `b` が更新されます。

### 忘却

`forgetting` は単なる知識減衰ではありません。

- 事実認識を初期事前信念へ戻す
- 知識量を減衰させる
- 過去の政党実績記憶を弱める
- 学習後の政策選好を初期選好へ少し戻す

ため、安定が長く続くほど過去の失敗の記憶も薄れ、同じ政治サイクルが再発する余地があります。

## 8. 選挙

v3.3の実際の投票効用は、下記の従来効用に `rentUtility` を加えます。参加確率にも支持方向に応じた組織動員を加えます。`rentFeedback=0` なら従来と同じ式・乱数順序です。

投票効用は概略、

```text
utility
  = econWeight × (
      1.25 × policy_preference
      + 0.45 × remembered_performance
    )
  + partisanship × party_identity
  + non_policy_component
```

です。

非政策要因には候補者魅力と確率的な揺らぎが含まれます。

### 投票参加

投票参加確率には、

- 基礎投票率
- 投票コスト
- 合理的無知
- 選好の強さ
- 陣営別動員力
- 所得による参加差
- 投票支援介入

が作用します。

そのため、

```text
人口内の支持率
≠ 得票率
≠ 議席比
≠ 実施される政策
```

です。

ここは本シミュレーションの重要な観察点です。

## 9. 選挙制度

### 9地区の小選挙区

## 10. 分配と所得

各市民は異なる稼得能力を持ちます。

通常の政権政策では裁量派Dが追加移転を行い、その原資は比例負担で調達されます。v3.0の手動政策カードはこの基礎部分に重ねる別の政策レイヤーであり、どちらの政権でも実施できます。財源はカードにより税・国債・通貨発行・歳出削減へ分かれます。

基礎移転と特定企業補助金の受益対象はシードで固定した架空の順位で決まります。一律給付は全員、低所得給付は各支払期の給付前稼得所得下位30%、上位課税は同上位20%を使います。いずれも現実の人種・性別などとは対応しません。

### 財政錯覚

受給の便益は認識する一方、自分が負担する財源を割り引いて認識する度合いです。

### 貨幣錯覚

家計が名目上の変化を実質改善の一部として知覚する度合いです。

### 格差の累積優位

`inequalityDrift > 0` では、高い稼得能力が相対的にさらに伸び、低い能力は相対的に低下します。

これは現実の格差発生メカニズムを推定したものではなく、**格差が自己増幅する世界を実験するための明示的な仮定**です。

## 11. 主な観測指標

### 人口支持

- 規則派支持: `b > 0.20`
- 裁量派支持: `b < -0.20`
- それ以外: 留保

### 事実認識の正確度

`z` と世界の真値 `θ` の距離を、`z ∈ [-1,1]` の最大誤差で正規化した値です。

これは経済学全般の「知能」ではありません。

### 平均知識量

市民の `k` の平均。

### 二極化度

```text
4 × P(b > 0.65) × P(b < -0.65)
```

両極に強い支持者が同時に存在すると高くなります。

### 陣営をまたぐ縁

ネットワークのうち、符号の異なる政策選好を結ぶリンクの割合。

### 期待ギャップ

```text
|実現インフレ - 予想インフレ|
```

### 所得 Gini

実質可処分所得から計算します。

### 規則への信頼

`policyCredibility ∈ [0,1]`

### 裁量の短期利得

金融サプライズによる一時的産出効果のうち、裁量政策に帰属する部分。供給価格ショックによる便益は含めません。

正にも負にもなります。

### 政策不確実性

政策急変・ルール逸脱変化の移動平均指標。

### 生活指数

概略:

```text
実質可処分所得の幾何平均
× インフレ不安定性ペナルティ
× 政策不確実性ペナルティ
```

を初期値100に正規化したものです。

これは現実の厚生指標ではありません。

## 13. 介入カード：税・給付・通貨を分ける

介入は **26種類**。情報・危機カード8種類、金融・財政・供給政策16種類に加え、v3.3で公開監査と給付の一般ルール化の2種類を追加しました。実際の制度をそのまま再現したものではなく、作用経路と財源を分離する縮約モデルです。

### 操作

画面上部の「政策カード」で操作パネルへ移動します。「税・給付」「通貨」「供給・制度」「情報・危機」の分類からカードを選び、実施案を確認して「この政策を決定」を押します。

新カードの規模は **0.5倍・1倍・2倍**。期間はカード固有、発効待ちは `interventionLag` で指定し、既定では決定の次の四半期に発効します。**発効待ちと経済への波及待ちは別です。** 金融カードは実施後に `policyLag = L` 四半期待ち、その後 `interventionSpread` 期へ分散した入力を物価計算に渡します。公共投資・訓練は `investmentLag` 期後に供給効果へ反映します。各待ち時間は決定時に記録するため、予約後のスライダー変更で決定済みの日程は動きません。

同じカードの予約・実施期間は重複させられません。最終支払期の処理後には、次期以降の再実施を予約できます。異なるカードは同時に実施でき、減税と増税、金融拡大と抑制はそれぞれ実際の金額・率で合算します。

**介入ptはゲームの操作予算であって、国の財源ではありません。** 1倍の操作コストは下表のとおりで、0.5倍・2倍では比例し端数を切り上げます。「制限なし」で無効になるのは操作pt制約だけです。税・国債・通貨発行の会計は無効になりません。

### 減税の財源

「所得税減税」は、既存給付を減らさずに減収を生みます。「歳出削減つき減税」は同額の既存給付を削減します。後者は納税者と受給者の間の分配を変えますが、それだけで国債を増やしません。

複数の減税を重ねても、基礎税率は0未満になりません。減税要求が基礎税額を超える場合は各減税を比例縮小します。歳出削減も既存の移転額を超えません。これらの上限は支払と財政会計の双方で一致させています。

増税・歳出削減による余剰は、まず追加債務の償還に使い、残りを政府準備金へ積みます。国債方式の政策を実施するときに準備金があれば、それを先に取り崩します。

このモデルの所得税減税は、所得分配と政府収支に作用します。限界税率の変化から労働供給・民間投資を最適化するモデルは未実装です。したがって、「減税したから生産力が必ず上がる」という加点も行いません。

### 国債給付と通貨発行給付

「一律給付〈国債〉」と「マネーのばらまき」は、1倍では同じ決定時総所得の3%を給付します。しかし、前者は新規国債、後者は新規通貨で財源を確保します。

国債給付だけでは貨幣増加率を書き換えません。給付を受け取ることと実物資源が増えることを同一視せず、実質GDPにも給付額を加算しません。政府の負債と家計の国債保有が同時に増えます。

通貨発行給付は、同じ給付額を金融側の追加発行にも反映します。四半期の基準総所得を `Yq`、仮定する貨幣残高／年間所得比を `rM`、当期発行財源を `H` とすると、

```text
q = H / (4 × rM × Yq)
I = 100 × [(1 + μ / 100) × (1 + q)⁴ − 1] − μ

I は実施した期の換算入力。物価へそのまま即時加算しない。
追加の物価側入力[t] = Σ w[j] × I[t − L − j]
Σ w[j] = 1、j = 0, ..., W−1

W = interventionSpread。既定W=4なら w = [1,2,2,1] / 6。
μ_物価計算[t] = 通常の遅延政策μ[t] + 追加の物価側入力[t]
```

です。`Yq` はマクロ計算直前の稼得所得、`H` は決定時に固定した実質予算です。これは貨幣残高の所得比を置いた換算近似であり、中央銀行・市中銀行の貸借対照表を逐一再現したものではありません。

一回給付は一回の追加発行、連続給付は8回の追加発行です。期間終了後に発行額は0へ戻りますが、期待・物価の調整まで瞬時に巻き戻す処理はありません。「貨幣供給の拡大／抑制」は別の金融操作で、家計へ直接給付しません。

金融介入は**ラグと分散波及を通った後**で、既存の `advanceMacro` に渡す貨幣増加率へ入ります。事前期待との差によって短期効果が決まります。支給が終了してもキューの入力を捨てず、すべて到着させます。給付を「失業率を下げるボーナス」として直接加算する処理はありません。

### 財政会計

新しい「財源と、その後」パネルは、税収、給付、公的購入、発行財源、新規国債、利払い、償還、準備金を別々に表示します。各期に次を検査します。

```text
税収 ＋ 通貨発行 ＋ 新規国債 ＋ 準備金取崩
 = 給付・移転 ＋ 公的購入 ＋ 利払い ＋ 国債償還 ＋ 準備金積立

当期末国債残高
 = 前期末国債残高 ＋ 新規発行 − 償還
 = 全市民の国債保有合計
```

以下の説明は既定の `sovereignDebtMode=indexed` に対応します。残高は実質額、国債は物価連動の債務として簡略化します。`nominal` では固定名目元本を毎期の物価で実質換算し、平均表面利率・借換え・増税充当率を使います。名目モードの残高式と利払い式は第35節を参照してください。家計の国債購入と元本償還は所得ではなく金融取引です。市民を選ぶと、追加国債の保有額と国債取引後の資金も確認できます。利息は所得として国債保有者へ支払います。

前期末債務に対して、毎期 `debtRealRate / 400` の実質利息と `debtRepay` の元本償還を計画し、比例の追加財源税で賄います。財源税の上限は当期総稼得所得の20%。上限に当たれば元本償還を縮小し、利息も賄えなければ不足分を借り換えます。この返済ルールは現実の政府行動を推定したものではなく、財政を閉じるための明示的な仮定です。

国債購入原資の不足は厳密には扱いません。国債取引後の資金が負なら、暗黙に既存貯蓄を取り崩す近似です。国債を金融資産として購入したこと自体を、家計の所得損失とは扱いません。

生活指数は可処分所得の幾何平均をもとにするため、一時的な給付でも上がりえます。**生活指数の上昇を、実質GDPや永続的な消費可能量の増加と読み替えないでください。**

### 公共投資・訓練・参入規制

公共投資と訓練は給付ではなく公的購入です。当期GDPへの自動的な財政乗数は付けず、支出から `investmentLag` 期後（既定4期）に設定された効率に応じて供給能力を改善します。購入に使った実質資源は、家計の国債購入などの金融取引と分けて記録されます。

```text
投資効果の新規到着 = 当該支出 / 支払期の総稼得所得 × 100 × 効率
物流設備ストック：毎期0.5%減衰、上限6pt
技能ストック：毎期1%減衰、上限4pt
参入規制緩和：設定された供給改善幅 × 規模、試行16期のみ
```

合計供給効果には、自然率が極端な負値へ下がらないための上限があります。係数は未較正で、`infrastructureEfficiency`・`trainingEfficiency`・`reformCapacity` を0にすれば該当便益を無効にできます。支出したから必ず有効な設備・技能が生まれるという事実認定ではありません。

供給改善は、構造的な産出損失を減らす項として組み込みます。

```text
純構造損失 = レント損失 − 政策による供給能力改善
構造調整後の自然率 = 基礎自然率 ＋ 0.55 × 純構造損失
```

フィリップス曲線の寄与度表では「制度・レント・供給能力」に含めます。自然率を変える供給側の政策と、所与の自然率のもとで短期曲線上を動かす金融サプライズは、同じものではありません。標準A→B→C実験はこれらの供給介入を除外しており、従来の経路のままです。

### 誰の政策として学習するか

政策決定時のR／D政権を記録します。財政による各市民の純受取変化は、帰属が成功すればその決定政権へ、失敗すれば現在の政権へ帰属します。給付の終了や債務返済による負担も経験へ入り、給付額をそのまま特定陣営の得票へ加算しません。

手動の金融介入は通常の自動政権政策への上書き実験です。`binding` は自動D政策を制約する係数で、手動カードの実施そのものを禁止しません。R政権でも手動でルールを逸脱でき、信頼や実績評価はその実施に応じて動きます。

過去の税・給付の帰属は扱いますが、将来税の現在価値を厳密に予測する家計最適化は実装していません。供給設備からの後年の便益や、同時に複数政権由来の金融介入が作用するケースの帰属も縮約です。

### 小さな比較実験

同じシナリオとシードで、国債給付・増税給付・通貨発行給付をそれぞれ開始し、発効後の家計、債務、貨幣増加率、金融サプライズを比べると違いが明瞭です。

A/B比較には「両条件に同じ政策を実施」を追加しました。例えば共通政策を「物流インフラ整備」、比較パラメータを `infrastructureEfficiency`、Aを0、Bを0.2にすると、同じ公的購入に対して供給改善が生まれる条件と生まれない条件を比較できます。共通カードは開始時に1倍で決定され、日程は各条件の `interventionLag` に従います。既に遊んでいる本編の介入履歴は引き継ぎません。

### 理論の出発点とモデル独自の部分

財政政策と金融政策の区別は [Federal Reserveの解説](https://www.federalreserve.gov/faqs/money_12855.htm)、通貨発行での家計給付と通常の金融操作の区別は [Richmond Fed, Helicopter Money](https://www.richmondfed.org/publications/research/econ_focus/2016/q2/jargon_alert) を参照しています。

一時的な所得移転を恒常的な資源増加と同一視しない視点は、[Friedman, The Permanent Income Hypothesis](https://www.nber.org/books-and-chapters/theory-consumption-function/permanent-income-hypothesis) と整合する問題設定です。ただし本作には厳密な恒常所得消費関数はありません。現行の政策カードの税率、期間、対象比率、供給改善係数、M/Y比、返済ルールは本作品独自の仮定です。

### フィリップス曲線の実験室

画面上部の **「短期／長期」** でパネルへ移動します。最初は本編の経済を表示します。**「A → B → C を再生」** で標準図の独立した統制実験を開始します。本編の状態・乱数・操作履歴は変更しません。本編に戻ると、開始前の再生・停止状態へ戻ります。

横軸は失業率、縦軸は年率インフレです。色の対応は、緑が選択期の短期曲線、紫の破線が前期の短期曲線、薄い青灰色が初期の短期曲線、金色が長期曲線です。白い点と点線は実現値の履歴で、短期曲線そのものではありません。

標準図では、Aが初期均衡、Bが変更直後、C∞が定常条件から計算した極限です。**C∞は参照点であって、将来の観測値を先に表示したものではありません。** 予見実験ではBとC∞が一致し、一時的供給危機ではAとC∞が一致します。

| 統制実験 | 条件 | 観察する経路 |
|---|---|---|
| 標準図：A → B → C | Q8に恒久的金融拡張、κ=1 | A→Bは旧曲線上、B→Cは期待上昇に伴う曲線の移動 |
| 波及ラグあり：金融拡張 | 同じ拡張、κ=0.4 | 物価の波及と期待調整が重なる経路 |
| 予見された金融拡張 | κ=1、当期政策を事前に知る | 短期曲線自体が移動し、失業率は自然率のまま |
| 引締め | Q8に恒久的金融引締め、κ=1 | 旧曲線上で失業上昇、その後は期待低下で曲線が下方移動 |
| 供給危機 | Q8に一回の供給ショック | 供給条件が曲線を動かし、物価と失業が同時に上昇 |

これらの5実験は本編の20シナリオとは別です。政治競争、移転・レント、ランダム攪乱、不確実性コスト、期待再アンカーは除外します。標準の初期値は μ=4%、g=2%、uⁿ=5%、a=0.8。引締めの初期μだけ8%です。期待調整速度と変更幅は変更できます。

観測期間は最低96四半期です。期待が遅い場合は、インフレ・期待・失業率が定常値との差 `10⁻⁷` 以内になるまで延長します（上限1600期）。期待調整0.02、変更幅4ptの標準図では875期です。**96期経っただけで「長期に到達」と扱ったり、終点をC∞に強制的に合わせたりしません。** 「C∞ の近傍へ」は、計算済みの最後の観測期へ移動するボタンです。

再生・停止、1期送り、時点のシーク、A・B・C∞近傍への移動に対応します。本編にも履歴スライダーがあり、図の実現点をクリックしてその期の曲線を確認できます。「最新へ」で本編の最新時点へ戻ります。

図には次の診断を付けています。

- **構造式の検査**：実現点と選択期の短期曲線の誤差、曲線の傾き、上下限の作動。
- **前期比の分解**：前期の曲線上を移動した分と、期待・供給・制度・係数によって曲線自体が変わった分。
- **失業率の水準分解**：基礎自然率、金融サプライズ、供給損失、実物景気、レント、不確実性、θの恒常効果、上下限補正。

統制実験の軸は実験全体で固定します。本編の軸は、同じ国の観測中には自動縮小せず、新しい範囲が必要な場合だけ拡張します。軸の伸縮によって同じ傾きが別の傾きに見える問題を抑えています。

**寄与度のマイナスは失業を下げる方向です。** これらはモデル内部の恒等的な分解であって、現実の因果効果の推定値ではありません。

「診断データ CSV」は、統制実験では初期状態を含む全計算期間を、本編では保存されている全履歴を出力します。選択中の時点だけを切り取る出力ではありません。従来の列に加えて、曲線の切片、傾き、線上誤差、上下限補正、曲線上の移動、曲線の移動、前期比分解の誤差を含みます。

## 16. A/B比較実験

「A/B 比較実験」では、**1パラメータだけを変えて複数シードで比較**できます。

例:

```text
A: expectationGain = 0.08
B: expectationGain = 0.58
観測期間: 80期
各条件: 16回
```

A/Bでは、

- 同一ペアのシード
- 共通の外生ショック系列

を使います。

ただし、個々の市民の信念更新や投票は途中の分岐によって乱数消費位置が変わりうるため、完全な決定論的ペア差分ではありません。

表示される標準偏差は**シミュレーション実行間のばらつき**です。

現実社会の推定誤差、信頼区間、因果効果の標準誤差ではありません。

### おすすめ実験

#### 期待形成速度

`expectationGain`

裁量刺激の短期的政治利益が何期持続するかを見る。

#### 忘却率

`forgetting`

一度学習した社会が再び同じ政策へ戻るかを見る。

#### 政策帰属精度

`attribution`

政策ラグがある社会で、有権者が誰を評価・処罰するかを見る。

#### 確認バイアス × 同類選好

`confirmation`, `homophily`

情報の正確性とは別に、ネットワーク構造だけで分断が維持されるかを見る。

#### 規則信頼

`credibilityGain`, `credibilityLoss`, `ruleReanchor`

ルールが単なる政策制約ではなく、期待形成装置として働く条件を見る。

#### 格差と政治参加

`inequalityDrift`, `turnoutIncomeBias`

所得分布の変化が投票者集団の構成をどう変えるかを見る。

## 17. 再現性

シード付き擬似乱数を使います。

また、

- 社会・信念用乱数
- 外生経済ショック用乱数

を分けています。

A/B比較では外生ショックを揃えやすくしています。

描画用の速度・フレームレートは経済モデルを進める乱数とは分離されています。統制実験の再生中は、SpaceとNが統制実験の再生・1期送りを操作します。本編の再生・1期送りボタンは本編表示へ戻してから操作します。

## 18. 実験の保存と再現

「実験を保存」でJSONを出力できます。

形式:

```json
{
  "schema": "belief-republic/2",
  "modelVersion": "3.3-endogenous-interests",
  "seed": "...",
  "initialParams": {},
  "ticks": 80,
  "actions": []
}
```

保存対象は主に、

- 初期条件
- シード
- 経過期数
- パラメータ変更履歴
- 介入履歴

です。

読み込み時には完成状態を直接ロードするのではなく、**初期条件から操作履歴を再実行して状態を再構成**します。

同じ `3.3-endogenous-interests` の記録は、新しい依存・組織・広告・動員の状態も操作から再構成します。`3.2-sovereign-sequence` と `3.1-policy-transmission` の記録で `rentFeedback` がない場合は **0を補い**、新しい経路を勝手に有効化せず既存結果を再現します。連続政策の自動実施は初期設定とパラメータ操作から再生成し、手動カードとして二重記録しません。モデル適用上限の先の期を要求する記録は拒否します。v1形式、`2.0-phillips`、`2.1-phillips-geometry`、`3.0-policy-cards` は初期条件と操作の移行として読み込み、旧版の完全再現を保証しない旨を表示します。未知のモデル版は拒否します。

新しい政策カードの操作は `strength` に0.5・1・2を記録します。旧カードで省略されている場合は1です。予約プログラム・債務・家計の国債保有・投資効果は、操作から再計算されます。

最大観測期間は10,000期、ファイルサイズは8MB、操作数は50,000件です。

## 26. モデルを読むときの注意

### 単一実行を結論にしない

シードを変えると結果は変わります。

「この実行でRが勝った」から、

```text
現実でもRが正しい
```

とは言えません。

同様にDについても言えません。

### パラメータは推定値ではない

多くの係数は、現象を分離して観察するための未較正パラメータです。

たとえば、

```text
confirmation = 0.48
```

だから現実の確認バイアスが48%だ、という意味ではありません。

### 因果方向を埋め込んでいる部分がある

たとえば、

- 規則遵守 → 信頼回復
- 政策急変 → 不確実性
- 誤認ドリフト → 真値から離れる
- 格差累積優位 → 所得分布拡大

などは明示的なモデル仮定です。

これらを0にして無効化し、結果がどの程度変わるかを見るのが重要です。

### 政治は二陣営へ強く圧縮されている

現実の政治争点は多次元です。

この作品は、

```text
貨幣ルール / 裁量
短期刺激 / 長期安定
移転
情報
期待
```

の相互作用を見るため、政治空間を意図的に圧縮しています。

## 27. このモデルで特に調べたい問い

この作品の中心テーマは「どちらが勝つか」より、次です。

### 正しい情報はいつ生き残るか

- 検証情報を増やせば十分なのか
- 確認バイアスが強ければ意味がないのか
- 知識拠点が孤立すれば社会へ広がらないのか

### 裁量刺激の政治的寿命は何で決まるか

- 期待形成速度
- 政策ラグ
- 貨幣錯覚
- 政策帰属
- 忘却
- 選挙周期

### なぜ失敗した政策が復活するのか

- 忘却
- 世代交代に相当するノイズ
- 安定による危機記憶の消失
- 新しいショック
- 党派性

## 34. v3.1：介入から物価・雇用への波及（v3.2でも継承）

### 旧版で不足していた点

v3.0の金融カードは `preparePolicyFrame()` の中で、既にラグ処理済みの通常政策へ即座に上乗せしていました。給付の発効待ち1期はありましたが、カード由来の金融入力は `policyLag` を経由していませんでした。Lを0・4・12期に変えても、1回のばらまき後のインフレ初動はすべて第1期でした。これは「Lがカードの経済効果にも適用される」という説明と整合しない実装でした。

v3.1では実施した入力を別キューへ保存し、指定した時点で物価側へ送ります。税・給付の会計を後の期へ移したわけではありません。

### 三つの時間と、その後の期待調整

| 段階 | 設定 | 既定 | 意味 |
|---|---|---:|---|
| 決定 → 実施・給付 | `interventionLag` | 1期 | 財政会計、給付、通貨発行を実施するまで |
| 実施 → 物価側の初回入力 | `policyLag` | 4期 | 金融カードの波及開始待ち。0なら実施期から |
| 初回入力 → 分散入力の完了 | `interventionSpread` | 4期 | 三角型重みで配分。1なら一括 |
| 入力 → 物価の調整 | `inflationAdjust = κ` | 0.24 | 既存の逐次調整式。待ち時間とは別 |
| 実現の観測 → 次期以降の期待 | `expectationGain` | 0.34 | 既存の適応的期待。予見・固定期待も別途選べる |
| 公的購入 → 能力改善 | `investmentLag` | 4期 | 金融のLとは別の供給側の完成待ち |

既定で経過0期に1回のばらまきを決定すると、経過1期に給付・発行を行い、経過5・6・7・8期に換算入力を1:2:2:1で物価側へ伝えます。最後の入力を受け取った後も、物価と期待は調整を続けます。

各実施分の重みの合計は1です。波及を長く設定しただけで投入量まで増やさないよう、次の検査を毎期行います。

```text
累積実施入力 − 累積到着入力 − 待機中の入力合計 = 0
```

ここでの入力の単位は「年率ポイント × 四半期」です。金融操作は負にもできるため、相殺前の総量と符号付きの純量を区別します。**波及の分配は給付額の分割払いではありません。** 財源の通貨発行と家計給付は実施期に一度だけ記録します。

通常の自動政権政策のLは従来どおり決定期から数えます。手動の金融カードのLは給付・操作実施期から数えます。カードへの分散カーネルは自動政権政策には追加しません。この違いは明示的なモデル設計です。

### インフレ率と物価水準を分ける

```text
P[0] = 100
log(P[t]/100) = log(P[t−1]/100) + log(1+π[t]/100)/4
```

画面に出るπは年率なので、四半期の物価水準には4分の1期分を複利で積み上げます。

一回の貨幣注入後にインフレ率が基準率へ戻っても、その間に積み上がった物価水準差は消えません。率が元に戻ったことと、価格が元に戻ったことを同一視しないでください。比較画面では `100 × [P_介入あり/P_介入なし − 1]` を表示します。

固定M/Yによる発行額換算と既存のμ−g型の物価式は縮約です。完全な貨幣残高・流通速度・実質取引量の恒等式を解いているわけではなく、注入率と最終物価差が厳密に同率になるような調整はしません。極端な長期実行では表示用の指数を `100 exp(700)` で止め、対数状態は保持します。表示上限に到達したことは明示します。

### 政策カードから直接比較する

政策を選択して **「介入あり／なしの波及を比較」** を押します。このボタンは本編へ政策を投入しません。

同じ `Republic.step()` と `advanceMacro()` を使って、介入あり・なしの二経路を160四半期計算します。次のグラフを別々に表示します。

1. インフレ率の差（ポイント）
2. 失業率の差（ポイント）
3. 物価水準の相対差（%）

横軸は決定からの経過四半期です。40・80・160期に表示を切り替えられます。観察期を動かすと、実際のインフレ・失業の水準、比較相手、貨幣入力、波及待ちの数値が表示されます。CSVには0〜160期の全データを出力します。

比較の初期値は本編の適用済みパラメータから作りますが、経路を隔離するため人口180人、規則派政権固定、選挙なし、外生供給・景気・個人所得ショックなし、格差ドリフトなし、不確実性コストなし、期待外挿なし、再アンカーなしにします。知識と分配、財政会計は残します。現在の本編の途中状態から分岐する機能ではありません。シードは両経路で同じです。

結果は**前期比ではなく、同じ時点での介入なしとの差**です。本編でインフレの前期比がマイナスでも、介入がなければさらに下がっていた可能性があります。したがって、政策の方向判定を単純な前期比だけで行わない設計にしています。

### 意図的に実装していない経路

貨幣発行を伴わない国債給付・増税給付・所得税減税は、家計と政府会計、分配、信念へ作用します。しかしこの版には、消費性向、貯蓄、金利、民間投資、労働供給、貨幣需要を通じた本格的な波及はありません。そのため、攪乱と政治反応を止めると、単純な給付・減税の物価差が0になる場合があります。**これは現実で効果が必ず0という定理ではなく、省略した経路があるという意味です。**

金融経路による雇用効果は、物価側に届いた入力と期首期待の差から当期の短期フィリップス曲線上で求めます。失業率だけを後処理で数期ずらす処理はしません。独立した採用・解雇ラグを入れる場合は、短期曲線そのものの動学を拡張する必要があります。政策発表時点だけの先行的な資産価格反応も含めていません。

これらのラグは可変の実験パラメータです。特定国で何か月後に何%動くという推定値ではありません。実際の金融政策の波及には長く変動的で不確実な遅れがあります。

## 35. v3.2：仮想の政策継承・名目国債・借換えの遅れ

### 35.1 シナリオの意味と、意味しないこと

追加した `japan_stress` の表示名は **「アベノミクス→サナエノミクス型：追加刺激の罠〈仮想〉」** です。金融緩和と財政拡張を引き継ぎ、追加刺激を強めていった場合のストレス経路を扱います。

これは実際の日本の年表、統計への較正、因果推定、将来予測ではありません。初期債務200%・初期平均利率0.6%・各段階の期間などは、実験用の架空の値です。経過25期を実際の政権発足日と対応させてはいません。

政府の給付と中央銀行の貨幣拡張は別の入力として指定し、両者が同時に継続する条件を置きます。政府が日銀の政策を直接操作するとの事実主張ではありません。また、仮想のR/D選挙結果にかかわらずこの経済政策日程を継続するという、外生的な政策継続の仮定があります。選挙、信念、家計、実績評価の通常計算は止めません。

政府の政策方針の背景は[施政方針演説（2026年2月20日）](https://www.kantei.go.jp/jp/105/statement/2026/0220shiseihoshin.html)を参照していますが、その政策意図と、このシナリオの悪化経路を同一視していません。

### 35.2 段階ごとの政策入力

`q` は経過四半期であり、政策を決定する時点です。給付の実施はさらに `interventionLag` 期後です。

| 段階 | 既定の日程 | 政策入力 |
|---|---|---|
| 第1段階 | q=0〜24で決定 | 追加貨幣増加率を初期8期で0から年率3ptへ。毎期の決定時総所得5%を国債給付 |
| 第2段階 | q=25から決定 | 追加貨幣増加率を加速させ、最大18ptへ。国債給付は12期で5%から15%へ。別途、通貨発行給付0.5% |
| 出口の比較 | `japan_exit` のq=65から決定 | 新しい追加金融操作・給付を停止。既決定分と到着待ちは履行。既存債務と借換負担は残る |

第2段階の追加金融入力は、`k=max(0,q−sequenceSwitch)` として、

```text
追加μ[q] = min(sequenceMoneyCeiling,
               sequenceEase + 0.10 k + sequenceAcceleration × k²)
```

です。係数は未較正です。実現インフレ率や失業率をこの式で直接書き換えることはありません。追加μは、既存の実施待ち・金融ラグ・三角分散・物価調整を経由します。給付は従来の財政会計に入るため、金融と財政を二重に新規資源として加算しません。

自動日程は政策を継続する外部条件なので介入ポイントを消費しません。現実の政策コストは別途、国債・税・通貨発行の会計へ計上します。手動カードとは別に `scripted:true` の予約を生成します。

### 35.3 失業を永久に下げる仕掛けではない

供給・期待条件を固定した金融経路は、従来どおりです。

```text
金融サプライズ = πᴹ − πᵉᴹ
金融による失業寄与 = −0.55 × phillips × 金融サプライズ
```

刺激の加速度を大きくすると、適応的期待が追いつくまで低失業を維持する区間が長くなりえます。しかし期待が追いついたり、追加μが上限で一定になったりすれば、短期効果は消耗します。高いインフレ率だけで失業が下がり続けるとはしません。

名目債務が増えても、物価や実質所得の増加が大きければ債務所得比は下がりえます。名目債務と債務所得比を別表示するのはこのためです。

期待と短期・長期の区別は [Richmond Fed, Inflation and Unemployment](https://www.richmondfed.org/press_room/speeches/jeffrey_m_lacker/2007/lacker_speech_20070411) を出発点にしています。曲線の数値係数、誤認、社会ネットワーク、政策日程の形は本作品独自です。

### 35.4 名目国債と市場金利

既存の `indexed` モードはそのまま残します。新しい `nominal` モードだけで、以下を追加します。

- 国債の名目元本は固定。
- 既発債の表面利率は借換えまで固定。
- 新発・借換債の利率は、期待インフレ・実質基準・上乗せから決定。
- 当期の利払いは、期首の平均表面利率を使用。
- 期末に借換えと新規発行を反映し、次期の平均利率を更新。

固定利付国債の表面利率を市場利回りと一斉に書き換えない設計は、[財務省の国債解説](https://www.mof.go.jp/jgbs/individual/how_to/index.htm)を踏まえています。名目金利と期待インフレ・実質金利の区別は[St. Louis FedのFisher関係の解説](https://www.stlouisfed.org/publications/regional-economist/april-2014/the-ups-and-downs-of-inflation-and-the-role-of-fed-credibility)を参照しています。

債券市場の期待 `e` は、前期までの家計の金融期待から別の速度で更新します。長期債の全期間構造をモデル化したものではなく、代表的な新発債を使う縮約です。

```text
e[t] = e[t−1] + bondExpectationGain × (πᵉᴹ[t−1] − e[t−1])
riskMemory[t] = 0.85 riskMemory[t−1] + 0.15 |金融サプライズ[t−1]|

premium = bondTermPremium
          + bondDebtRisk × max(前期債務 / 前期年間所得 − 1, 0)
          + bondInflationRisk × riskMemory
```

利率は、四半期の支払率を年率表示した表面利率です。期待インフレと実質基準は年率の複利率なので、換算を区別します。

```text
fairCoupon = 400 × {[(1 + 実質基準/100)(1 + e/100)]^(1/4) − 1}
要求表面利率 = fairCoupon + premium
市場表面利率[t] = 市場表面利率[t−1]
                  + bondYieldGain × (要求表面利率 − 市場表面利率[t−1])
```

0〜80%の安全範囲を超える場合は上限・下限と警告を表示します。この制限は経済理論ではありません。プレミアムの債務感応度や予想誤差感応度は0にできます。「日本の債務がこの値なら何%」という実証式ではありません。

### 35.5 元本・利払い・借換えの会計

`P` は物価指数を100で割った値、`B` は名目元本、`D=B/P` は内部会計で保持する実質元本です。

```text
D_期首再評価 = D_前期末 × P_前期 / P_当期
当期利払い（実質） = D_期首再評価 × 平均表面利率_期首 / 400
B_当期末 = B_前期末 + P_当期 × (純新規発行 − 元本償還)
```

家計が保有する対応債権も同率で実質再評価するため、政府債務と家計保有は一致します。インフレにより固定名目債務の実質負担が減る経路を省略していません。

通常の償還を反映した残高を `S`、新規発行を `J`、借換比率を `ρ`、前期の平均表面利率を `c`、新発利率を `y` とすると、

```text
借換額 = ρ S
新平均表面利率 = [(1−ρ) S c + (ρ S + J) y] / (S + J)
```

です。借換額は純債務増加へ加算しません。満期分布は毎期一定割合が満期になる幾何分布近似です。既定ρ=0.03は平均約33四半期に相当しますが、日本国債の満期構成の推定ではありません。

利払い・予定償還のうち当期増税で賄う割合は `serviceTaxCover` です。仮想シナリオは0なので、未充当利払いは新規発行へ入り、その新規債務にも次期以降の利払いが生じます。

`japan_exit` は新しい刺激を止める比較であって、自動的な財政再建ではありません。利払いまで借入で賄い続ければ、インフレ低下後も債務が増ええます。増税充当率を上げる場合との比較は別に行ってください。

### 35.6 名目金利の全額を景気悪化へ使わない

市場表面利率 `y` から期待インフレを除いた実質借入率を計算します。

```text
実質借入率 = 100 × {(1 + y/400)^4 / (1 + e/100) − 1}
```

実質基準と期間プレミアムだけを含む基準借入率から上振れた部分を、`creditSpreadCost` 倍し、`creditSpreadLag` 期後に産出損失へ入れます。インフレ補償分まで実物損失へ数える処理はしていません。

この損失は短期曲線の分解に `uCredit` として加わります。

```text
uCredit = 0.55 × 遅れて到着した実質借入コスト
Ω = 既存のその他寄与 + uCredit
u = uⁿ − β(π − πᵉ − ν) + Ω
```

描画側で点を曲線へ強制移動するのではなく、本編と同じ構造式のΩへ加えます。金色の長期参照線は、信用負担を含む追加的実物負担も解消した条件の線です。信用負担が持続する経路を、その参照条件への収束と同一視しません。

| `sovereignTerminal` | モデル適用上限によって終了したか |

A/B比較でも新発利率・平均表面利率・利払い比を出力します。停止した実行は実際の観測期数を併記するため、異なる時点の結果を同時点の因果効果として読まないでください。

カード1枚の「介入あり／なしの波及比較」は、連続政策、初期債務、名目国債モードも無効にした統制実験です。連続政策全体や国債市場を比較するには、本編の複数実行かA/B比較を使います。画面の比較条件にもその違いを表示します。

### 35.8 適用上限

名目モードでは、債務 / 年間所得が1000%に達するか、当期利払い / 当期所得が100%に達した場合に観測を停止します。これは、税制変更、家計の国債購入余力、債務再編やデフォルトの処理を実装していないための**モデル適用上限**です。実際の国家破綻の判定基準ではありません。

停止後は状態を先へ進めません。ブラウザの再生、A/B比較、保存の再現処理も終端を扱います。停止地点までのCSVと保存は可能です。より先の架空の数値を延々と生成して、分析結果のように見せることはしません。

## 36. v3.3：給付から組織が育つ政治的フィードバック

### 36.1 以前のモデルと何が違うか

従来の `lobby` は外生的に設定するレント・受益集団の係数でした。給付額・税負担は家計経験や政策評価へ入りましたが、受給の反復から組織が育ち、その組織が広告・動員・次の政策へ働きかける状態変数はありませんでした。

v3.3は次の経路を追加します。

```text
実際に受け取った給付・補助金と財源負担
    ↓ 組織化待ち（既定2四半期）
継続受給の記憶・提供者の記憶
    ↓ 利益の集中・自己利益・費用認知
地区の受益組織が形成される
    ├─ 党派的媒体の露出を増やす
    ├─ 依存と継続期待が投票効用へ入る
    ├─ 支持方向が合う有権者の参加を増やす
    └─ 通常移転の削減を一部阻む
           ↓ 通常の政策ラグと税財源
       実際の追加移転・税負担
           ↓
       次の受給と政治的評価
```

給付の決定時点では組織は増えません。`interventionLag=1` と `rentLag=2` の場合、経過0期に決定した給付は1期に実施され、3期に初めてその受給情報が組織経路へ届きます。金融側は別の `policyLag` と `interventionSpread` を使います。政治的な便益認知と、遅れて到着する物価・負担を同じ時点には置きません。

### 36.2 「受給」「利権」「不正」は同義ではない

ここでいう利権は、受益を継続させようとする政治的な利害と組織の代理です。給付を受けたというだけで、違法行為・買収・汚職を認定するものではありません。投票は秘密かつ確率的で、受給資格を投票先によって変更する処理はありません。

また、組織力と広告圧力は0〜1等の無次元の代理指標です。通貨・献金口座・広告費の残高ではなく、受益から形成される活動能力を縮約しています。給付金を架空の広告予算へ複製せず、政府会計・家計の国債保有に二重計上しません。政治活動費の貨幣会計や最適な献金額は未実装です。

### 36.3 入力は実際の会計から取る

`settleFiscal()` で通常の移転、追加給付、減税、増税、給付削減、債務返済財源税を処理すると同時に、各市民へ以下を記録します。

| 変数 | 内容 |
|---|---|
| `rentBenefit` | 当期の通常移転と追加給付・補助金の総受取。実質額 |
| `rentTax` | 当期に実際に課された財源負担。実質額 |
| `rentBenefitSide` | 給付の決定者をR=+1、D=−1で重み付けした受取 |
| `rentTaxSide` | 負担の発生元を同じ符号で重み付けした額 |

原則として市民全員の `rentBenefit` の和は財政台帳の家計移転に、`rentTax` の和は台帳の税収に一致します。給付に対する当期課税は純便益を小さくし、国債財源の場合は後に発生する返済財源税が負担へ入ります。

国債購入、償還元本、利払い受取、公的資源購入、単なる貨幣供給操作を新しい給付としては数えません。減税は財源負担を減らしますが、新しい給付提供者への受給実績を捏造しません。金融緩和だけで金融業界が組織化する経路や、公共調達の受注業者の組織化は本版では未実装です。

インフレと家計悪化に対する反応は従来の期待・政策評価・家計経験の経路に残します。ここで同じインフレ負担を再び財政台帳へ書き込むことはありません。

### 36.4 依存の記憶と帰属

市民ごとに、給付の所得依存度を計算します。

```text
scaleᵢ = max(小さい安全下限, 当期稼得所得ᵢ + 給付ᵢ)
xᵢ     = clamp(給付ᵢ / scaleᵢ, 0, 1)
cᵢ     = clamp(財源負担ᵢ / scaleᵢ, 0, 1)
```

厳密には安全下限に地区ではなく社会の一人当たり所得の10%も使います。これらを給付実施時に記録し、決定済みの `rentLag` 後に読み込みます。

`rentStake` は受給があるとき `rentLearning` で当該依存度へ近づき、受給がゼロのときは `rentMemoryDecay` で減衰します。提供者への符号付き記憶は同じ方法で更新します。給付終了後も継続期待は即座には消えません。ただし通常の給付が残っている場合、個別カードの終了だけで依存全体がゼロになるわけではありません。

提供者の認識精度は `attribution`、会計監査の効果、透明性から決まり、不正確な部分は受給時の現政権へ帰属させます。観測待ちの間に政権が交代しても、実施時の政権は履歴に保存されています。

### 36.5 集中した便益と組織形成

9地区それぞれに組織資本 `power ∈ [0,1]` を置きます。

```text
集中度 C = 1 − (Σ給付ᵢ)² / (地区人口 × Σ給付ᵢ²)
```

全員が同額を受け取る場合は0、少数へ集中するほど1へ近づきます。給付がゼロのときは0です。

組織化への入力は、費用を認識したあとの純便益、`selfInterest`、集中度から作ります。

```text
費用認識 v = 1 − fiscalIllusion × (1 − 透明性)
活動誘因   = 平均 max(0, xᵢ − v cᵢ)
形成入力 I = clamp(selfInterest × 活動誘因 / 0.08)
             × [0.25 + 0.75 clamp(rentConcentration × C)]

O[t+1] = clamp((1 − rentOrgDecay) O[t]
              + rentOrgGain × I × (1 − O[t]))
```

この関数形・0.08等の閾値は未較正です。集中すれば現実に何%の確率で団体ができる、という推定ではありません。同額の給付でも、配り方によって組織化速度が変わる仮説を検証するための指定です。

支給終了後は入力が弱まり、組織資本が減衰します。連絡網や事務局が支給停止の瞬間に消える処理はありません。

### 36.6 どの陣営を支持するか

支持方向は次の二つを分けています。

**提供者への帰属**は実際のR/Dへ対称的に働きます。Rが給付を提供した場合も、Rへの政治的支持を生めます。

**継続への期待**は、通常のR/Dの移転額を比較します。

```text
R提示額 = 基礎移転 + Rの削減抵抗による保護分
D提示額 = 基礎移転 + 裁量制約後の追加移転 + Dの保護分
継続差  = (R提示額 − D提示額) / max(R提示額, D提示額)
方向    = tanh(提供者への帰属係数 × 提供者の記憶
               + 継続期待係数 × 継続差)
```

同じ政策を提示するなら継続差は0です。既定ではDが通常の追加移転を多く提示するため、この経路はDを支持しやすくなりますが、Dの名前自体に加点していません。一般ルールや失効条項が強いほど、政治家個人への帰属と移転削減への抵抗は弱まります。

この継続差による評価は、通常移転の受給対象にある市民だけへ適用します。対象外の市民が一律給付を受けても、将来の通常移転を受け取れると勝手に仮定しません。その人への影響は提供者への関係記憶、組織・広告、負担認知から生じます。

提示額の予想は簡略化されています。政党ごとに給付対象や制度を最適化する選挙公約モデルではなく、通常移転額を継続性の代理として使います。

### 36.7 広告・投票効用・動員

組織の支持方向は、依存度で重み付けした地区の平均です。地区60%・全国40%の広告圧力が、既存の党派媒体でR/Dどちらの情報に接触するかを変えます。検証済み媒体の真値信号を上書きせず、正確な知識を持った有権者にD支持を強制することもありません。

投票時には、給付依存、自己利益、組織力、提供者、継続期待から作る効用を従来の投票効用に加えます。同時に、受益組織と支持方向が合う有権者の投票参加確率を上げます。非受益者や負担超過の市民には、透明性に応じた反発が入ります。

```text
投票効用 = 従来の政策・経験・党派・候補者評価 + rentUtility
参加確率 = clamp(従来の参加確率の基礎値 + 組織動員)
```

`rentVoteWeight` と `rentMobilization` は独立して0にできます。実際の票は依然として確率的に決まり、組織力が1でも全員の票を獲得する処理はありません。

### 36.8 組織が政策を残す経路

過去に実施された通常の追加移転の規模を `rentFloorMemory` として記憶します。今の政権がそれより低い移転を決定しようとすると、組織力と制度条件に応じて削減の一部が阻まれます。

```text
保護額 = max(0, 記憶された移転水準 − 政権が決める移転水準)
         × 利権強度 × 削減抵抗係数 × 組織力
         × (1 − 透明性) × (1 − 一般ルール)
```

保護されるのは過去の通常移転です。一度の手動給付全額をそのまま恒久予算へ変換しません。自動政権政策の実施ラグを通し、実施後は既存の比例課税・移転の会計で処理します。Dが提示する額の方が大きければ保護額は0です。Rへの政権交代後にも、給付削減が部分的に阻まれる場合があります。

利権経路を途中で0にしても、既に政策キューへ入った保護額は取り消しません。「無効化」と「過去の決定を遡って消す」を混同しないためです。

### 36.13 理論との関係と限界

- [Battaglini & Palfrey, Organizing for Collective Action: Olson Revisited, NBER Working Paper 30991](https://www.nber.org/papers/w30991) は、利益の集中と集団行動を理論的に扱います。
- [Alston, Libecap & Mueller, Interest Groups, Information Manipulation in the Media, and Public Policy, NBER Working Paper 15865](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1583806) は、限られた資源を持つ利益集団、媒体、政策の関係を扱います。
