積立投資シミュレーター

初期投資額、毎月の積立額、想定年利、運用期間、インフレ率、ボラティリティを指定し、 複利運用の想定評価額と価格変動を含む将来レンジを試算します。条件はURLのGETクエリに保存され、そのまま共有できます。

資産推移と変動レンジ

800経路のモンテカルロ・シミュレーション。積立は各月末に行う前提です。

本ツールは将来の成果を保証するものではありません。税金、信託報酬、売買手数料、為替、相場の急変、リターン分布の歪みなどは簡略化しています。投資判断は商品資料、リスク、手数料、税制、自身の許容損失を確認したうえで行ってください。

この積立投資シミュレーターで分かること

一定額を毎月積み立てた場合の投資元本、複利運用後の想定評価額、インフレを差し引いた実質価値を確認できます。 年利だけで一本の直線を描くのではなく、ボラティリティを使って複数の価格経路を生成し、結果のばらつきを帯で表示します。

計算方法と前提

  • 年利は月次複利に変換し、各月末に積立額を追加します。
  • 価格変動は対数正規モデルで近似し、同じGETクエリなら同じ乱数系列を再現します。
  • インフレ調整後の金額は、最終評価額を累積物価上昇率で割って算出します。
  • 10〜90%レンジは保証区間ではなく、入力した仮定の下での試算分布です。
