1. 問題設定：均衡の存在、価格の収束、主体の行動

一般均衡理論に力学を導入するとは、財の需要と供給が一致する価格を求める理論に、そこへ至るまでの時間発展を加えることだ。静学が与えるのは条件 \(Z(p^\ast)=0\) であり、動学が必要とするのは状態方程式 \(\dot x=F(x)\) である。後者は前者から一意には決まらない。

出発点は、スティーヴ・スメールの Mathematical Problems for the Next Century に収められた第8問題だ。1998年の問題文は、価格調整を含む一般均衡モデルを求め、とりわけ個々の経済主体の行動から価格の時間発展を説明することを望ましい要件としている。[1]

以下では、既存の定理と、本稿で計算を追える形に再構成したモデルを区別する。一般問題全体の解決を宣言するのではなく、何を追加すればどの結論が証明でき、何を追加してもまだ足りないかを具体化する。

動的な一般均衡モデルが答えるべき六つの問い
問い数理的な内容それだけでは分からないこと
存在市場を清算する価格 p* が存在する経済がその価格へ向かうか
定常点の一致F(x*) = 0 と競争均衡の条件が整合するその定常点が安定か
局所安定性十分近い初期状態から均衡へ戻る遠い初期状態から戻るか
大域収束明示した領域内の初期状態から均衡へ近づく主体がその調整則を実行するか
実装可能性観測情報、取引制度、計算能力で更新則を実行できる実際にその行動が選ばれるか
実証性注文、在庫、約定、価格変更のデータを説明する別の市場制度や時期にも適用できるか

この区別を保てば、市場の調整能力を評価するときにも、存在定理を収束の証拠にすることや、一つの非収束例をすべての市場への判決にすることを避けられる。

2. 静学の出発点：個人の選択から超過需要へ

2.1 純粋交換経済

財を i = 1,…,L、消費者を a = 1,…,N とする。消費者 a は初期保有 \(\omega_{a}\)、効用関数 \(u_{a}\) を持つ。正の価格 p に対して、価格を所与として次の問題を解く。

\[\begin{aligned}x_a(p)&\in\underset{x\ge 0}{\arg\max}\;u_a(x)\\[2pt]\text{subject to}\quad&p\cdot x\le p\cdot\omega_a\end{aligned}\]

総初期保有を W = \(\sum_{a}\)\(\omega_{a}\) とすると、超過需要は

\[Z(p)=\sum_a x_a(p)-W\]

である。消費者が局所的に非飽和であり最適解が存在すれば、正価格では予算を使い切る。その結果、個々の予算式を足して p · Z(p) = 0 が得られる。これは、売却可能な保有財の価値と購入需要の価値が一致することを表す。

価格をすべて同じ正の倍率で変えると予算集合は変わらない。そのため需要が一意に定まる場合、Z(λp) = Z(p) となる。効用最大化は需要の根拠を与えるが、誰が価格をいつ変更するかは、この最適化問題にはまだ含まれていない。

2.2 必要な正則性を別に置く

連続な効用、凸な選好、適切な初期保有などは静的な存在定理の基本的条件になる。アロー＝ドブリューの原論文は、消費・交換・生産を統合したモデルで存在を証明した。[2] ただし、需要が一意、微分可能、境界まで有限という性質は、それぞれ追加の条件だ。

本稿で常微分方程式を扱う箇所では、断りのない限り、超過需要が正価格領域で単一値かつ局所リプシッツ連続であると仮定する。ヤコビ行列を使う箇所では C¹ 級を仮定する。非一意な需要を含めるなら、需要対応や微分包含による記述へ進む必要がある。

2.3 生産を加える場合

企業 f の実行可能な純産出集合を \(Y_{f}\) とし、負の成分を投入、正の成分を産出とする。企業は \(y_{f}\)(p) ∈ arg \(\max_{y\in Y_f}\) p · y を選ぶ。企業利潤を消費者へ持分に従って分配すれば、超過需要は次になる。

\[Z(p)=\sum_a x_a(p)-\sum_a\omega_a-\sum_f y_f(p)\]

利潤分配と予算制約を整合させればワルラスの法則は保たれる。だが、生産の時間、設備、受注残、在庫を扱うには、それらを状態変数として追加しなければならない。静的な供給関数を置くだけでは、生産調整の時間発展にはならない。

3. 価格空間と三つの公理

3.1 経済的に意味を持つのは価格の比

純粋交換モデルでは価格の共通倍率が需要を変えない。したがって、正価格錐 \(\mathbb{R}^{L}_{++}\) の各半直線を一つの点と考える。計算上は、代表元を単体の内部に取ればよい。

\[\begin{aligned}q_i&=\frac{p_i}{\sum_j p_j}\\[2pt]\Delta^\circ&=\left\{q\in\mathbb{R}^L:q_i>0,\ \sum_i q_i=1\right\}\end{aligned}\]

相対価格の自由度は L−1 になる。たとえば2財では価格比が一つ、3財では二つになる。財の数量単位を変更すれば価格の数値も変わるため、調整速度の係数と単位の対応も指定する必要がある。本稿の具体例では、各財の総初期保有を1とする単位を使う。

なお、1財だけの純粋交換一般均衡では、ワルラスの法則から正価格で Z = 0 となる。「一つの市場で需要超過なら価格が上がる」という部分均衡モデルは、他市場や所得を外部に置いたモデルであり、この1財経済とは異なる。

3.2 原問題の三公理を正確に読む

  1. 0次同次性：Z(λp) = Z(p)。価格の共通倍率は相対的な取引条件を変えない。
  2. ワルラスの法則：p · Z(p) = 0。超過需要を現在の価格で評価した総額はゼロになる。
  3. 境界での内向き条件：\(p_{i}\) = 0 なら \(Z_{i}\)(p) > 0。無料の財への需要超過が、その価格を正の領域へ押し戻す。

ここでは価格がすべてゼロの点を除く。また、存在や微分方程式の議論には連続性などを補う必要がある。第3条件は、個人の合理性だけから常に得られる性質ではない。無料の財の需要が発散して有限な Z を定義できない場合もあり、境界への連続拡張ができるモデルと、内部だけで定義するモデルを区別する。

3.3 ワルラスの法則は球面への接線条件

p · Z(p) = 0 は、Z が原点からの方向 p に直交することを意味する。したがって加法的な調整 ṗ = Z(p) では

\[\frac{d}{dt}\|p\|^2=2p\cdot\dot p=2p\cdot Z(p)=0\]

となり、価格は球面上を動く。ただし、∑\(Z_{i}\) = 0 は一般には成立しない。単体上でそのまま q̇ = Z(q) と書くと、価格の和が1という制約を壊す。球面と単体の正規化を取り違えないことが、動学の第一の整合性条件になる。

4. 均衡の存在を動学から切り離して証明する

次は、原問題の公理に連続性を加えたときの、コンパクトな単体を使う存在証明である。アロー＝ドブリューの最も一般的な存在定理を再証明するものではなく、本稿の仮定に限定した補助命題だ。

命題1：内点均衡の存在。閉単体 Δ 上で Z が連続、q · Z(q) = 0、\(q_{i}\) = 0 ⇒ \(Z_{i}\)(q) > 0 を満たすとする。このとき、Z(q*) = 0 を満たす q* ∈ Δ° が少なくとも一つ存在する。

証明。\(Z_{i}^{+}\)(q) = max{\(Z_{i}\)(q),0} と置き、次の連続写像を作る。

\[T_i(q)=\frac{q_i+Z_i^+(q)}{1+\sum_j Z_j^+(q)}\]

T は Δ を Δ に写すので、ブラウワーの不動点定理により T(q*) = q* となる点がある。s = ∑\(Z_{i}^{+}\)(q*) とすると、不動点条件は \(Z_{i}^{+}\)(q*) = s \(q_{i}^{\ast}\) となる。もし s > 0 なら、\(q_{i}^{\ast}\) > 0 の成分で \(Z_{i}\)(q*) = s \(q_{i}^{\ast}\) であり、

\[q^\ast\cdot Z(q^\ast)=s\sum_i(q_i^\ast)^2>0\]

となってワルラスの法則に反する。よって s = 0、すなわち Z(q*) ≤ 0 である。境界条件から q* は内部にあり、全成分が正の q* と Z ≤ 0 の内積がゼロになるには Z(q*) = 0 でなければならない。□

この証明には時間が一度も登場しない。不動点が存在しても、自然に見える価格調整がそこへ到達するとは限らない。また、無料の財を許す一般形では、均衡を \(p\ge0,\quad Z(p)\le0,\quad p_iZ_i(p)=0\) という相補性条件で書く。正価格の内点なら Z = 0 に戻る。

後述する Cobb–Douglas 例は境界で需要が発散し、Scarf 型の例は厳密な内向き条件を満たさない。この命題の仮定は十分条件であり、すべての具体例が従う共通の必要条件ではない。

5. 価格調整則を構成する

5.1 タトンマンが表す市場制度

タトンマン（tâtonnement、模索過程）では、需要と供給の申告に応じて仮の価格を更新する。純粋な形では、均衡に達する前の注文はまだ実際の取引にならない。このため初期保有を固定して Z(p) を計算できる。これは明確な制度上の仮定である。

最も素朴な規則は \(\dot p_i\) = \(\kappa_{i}\)\(Z_{i}\)(p)、\(\kappa_{i}\) > 0 だ。需要超過で値上げ、供給超過で値下げする。ただし、速度が全財で同一の場合に成り立つ球面保存は、異なる速度係数をそのまま入れると一般には失われる。

5.2 単体上の加法的な正規化

1 を全成分が1のベクトルとすると、

\[\dot q=\kappa\left[Z(q)-q\left(\mathbf{1}^{\mathsf T}Z(q)\right)\right]\]

は ∑\(\dot q_{i}\) = 0 を満たす。定常点では Z = cq となるが、ワルラスの法則から c‖q‖² = 0、したがって Z = 0 となる。厳密な境界内向き条件があれば、境界で \(\dot q_{i}\) > 0 でもある。

元の加法系 ṗ = κZ(p) から q = p/(∑p) を微分すると、この式の右辺にさらに 1/(∑p) が掛かる。正の時間尺度を変えれば相対価格の軌道は対応するが、時計の進み方まで同じだと見なしてはいけない。

5.3 本稿の主モデル：乗法的な価格調整

\[\dot q_i=\kappa q_i Z_i(q),\qquad \kappa>0\]

ワルラスの法則から ∑\(\dot q_{i}\) = κq · Z = 0 となる。したがって、初期価格の和が1なら、その和は保存される。解が内部に存在する間は

\[q_i(t)=q_i(0)\exp\left[\kappa\int_0^t Z_i(q(s))\,ds\right]\]

であり、積分が有限な有限時刻には正値性が保たれる。境界付近の特異性がある場合、大域的に内部に留まることは別に証明する。内点では \(q_{i}\) > 0 なので、q̇ = 0 と Z = 0 は同値になる。

相対価格比の変化は d log(\(q_{i}\)/\(q_{j}\))/dt = κ(\(Z_{i}\) − \(Z_{j}\)) となる。この規則は価格の正値性と尺度の扱いに便利だが、効用最大化から自動的に導かれたわけではない。

5.4 財ごとに更新速度が違う場合

単体上で速度 \(\kappa_{i}\) を使うなら、次のように平均項を引く。

\[\dot q_i=q_i\left[\kappa_iZ_i(q)-\sum_j q_j\kappa_jZ_j(q)\right]\]

和は常に保存される。内点定常点では \(\kappa_{i}\)\(Z_{i}\) = c が全財で共通になる。ワルラスの法則を使うと c∑\(q_{i}\)/\(\kappa_{i}\) = 0 なので c = 0 となり、やはり Z = 0 と一致する。

一方、境界での乗法則は \(q_{i}\) = 0 を固定してしまう場合がある。ゼロ価格の財を含む均衡を調べるなら、内部の議論をそのまま流用せず、相補性と境界の更新規則を指定する。

5.5 価格を変更するのは誰か

競争均衡の消費者や企業は、価格を所与として数量を選ぶ。したがって、その最適化だけから価格変更の主体は決まらない。競売人が市場ごとの申告を集計するのか、売り手が注文や在庫から提示価格を変えるのか、取引所の規則が価格を変えるのかを定める必要がある。

自財の超過需要しか使わない式でも、それは個々の売り手にとって自動的に観測可能とは限らない。市場全体の未充足注文を知る仕組みが必要になる。一方、単体への正規化は共通の表示尺度を選ぶ操作であり、現実の主体すべてが価格の和を計算するという行動仮定とは区別できる。分散的な実装を論じるには、数量の選択と価格の改定の両方について情報の所在を示すことが必要だ。

6. 局所安定性：尺度由来の零固有値を除いて判定する

内点均衡 q* の周囲で超過需要を線形化し、J = DZ(q*) とする。0次同次性を微分すると Jq* = 0、ワルラスの法則を微分すると \((q^\ast)^{\mathsf T}J\) = 0 を得る。均衡での価格調整の微分は

\[B=\kappa\operatorname{diag}(q^\ast)J\]

になる。ただし調べるべき摂動は ∑δ\(q_{i}\) = 0 を満たすものだけだ。単体の接空間 T = {v : \(\mathbf{1}^{\mathsf T}v\) = 0} の正規直交基底を列に持つ行列 Q を選ぶと、独立な変数に対する行列は

\[A=Q^{\mathsf T}BQ\]

となる。全空間の B に必ず現れる尺度方向の零固有値を、相対価格の不安定性と取り違えてはいけない。

  • A の全固有値の実部が負なら、均衡は局所漸近安定になる。
  • 実部が正の固有値があれば、均衡は不安定になる。
  • 正の実部を持つ固有値がなく、実部がゼロの固有値が残る場合、線形化だけでは結論できない。非線形項や保存量を調べる必要がある。

実部は減衰または増幅、虚部は局所的な回転を表す。各市場の自己価格効果が負でも、市場間の交差効果が全体の固有値を変える。個々の市場を一つずつ眺めるだけでは、連結した経済全体の安定性は判定できない。

十分条件の一つは (A+\(A^{\mathsf T}\))/2 が負定値であることだ。このとき V(v) = ‖v‖²/2 は局所的に減少する。ただし、安定な非対称行列すべてがこの条件を満たすわけではなく、必要条件ではない。

7. 大域収束を証明する追加条件

局所安定性から、遠方の初期価格を含む収束は出てこない。大域的な結論には、軌道を制御する量が必要になる。その一つが、均衡価格からの相対エントロピー型の関数である。

命題2：KL型関数による大域収束。Z が Δ° で局所リプシッツ連続、q · Z(q) = 0 を満たし、内点均衡 q* が存在するとする。さらに、すべての q ≠ q* に対して q* · Z(q) > 0 と仮定する。このとき主モデル \(\dot q_{i}\) = κ\(q_{i}\)\(Z_{i}\) は、任意の内点初期価格から q* へ収束する。

証明。次の関数を使う。

\[\begin{aligned}V(q)&=D_{\mathrm{KL}}(q^\ast\|q)=\sum_i q_i^\ast\log\frac{q_i^\ast}{q_i}\ge 0\\[3pt]\dot V(q)&=-\sum_i q_i^\ast\frac{\dot q_i}{q_i}=-\kappa q^\ast\cdot Z(q)<0\qquad(q\ne q^\ast)\end{aligned}\]

全成分 \(q_{i}^{\ast}\) が正なので、q が単体の境界へ近づくと V は無限大になる。V が増えないことから、軌道は内部のコンパクトな劣位集合に閉じ込められる。局所リプシッツ性とこの有界性から解は全時刻へ延長でき、V̇ = 0 の最大不変集合は q* のみとなる。ラサールの不変原理により収束する。□

証明で働いているのは q* · Z(q) > 0 という追加の符号条件だ。これは、価格が均衡から外れると V を減らす方向へ超過需要が向くことを意味する。消費者の効用最大化やワルラスの法則だけから、この符号は導けない。

KLという形を使っても、市場が情報量や社会厚生を最大化していることにはならない。ここでの V は軌道を評価するために選んだ数学的関数である。

8. 解ける例：Cobb–Douglas交換経済

8.1 需要の導出

各財の総初期保有を \(W_{i}\) = 1 とし、すべての消費者が共通の支出比率 \(\alpha_{i}\) > 0、∑\(\alpha_{i}\) = 1 を持つとする。効用は \(u_{a}\)(x) = \(\prod_{i}\)\(x_{i}^{\alpha_{i}}\) である。消費者 a の所得は q · \(\omega_{a}\) なので、需要は \(x_{ai}\) = \(\alpha_{i}\)(q · \(\omega_{a}\))/\(q_{i}\) となる。

所得を全員について足すと q · W = ∑\(q_{i}\) = 1 となる。したがって集計超過需要は

\[Z_i^S(q)=\frac{\alpha_i}{q_i}-1\]

となる。元の正価格錐では \(Z_{i}^{S}\)(p) = \(\alpha_{i}\)(\(\sum_{j}\)\(p_{j}\))/\(p_{i}\) − 1 と書け、0次同次性も確認できる。

8.2 価格は指数的に収束する

主モデルに代入すると、非線形に見えた価格調整が線形になる。

\[\begin{aligned}\dot q_i&=\kappa q_i\left(\frac{\alpha_i}{q_i}-1\right)=\kappa(\alpha_i-q_i)\\[3pt]q_i(t)&=\alpha_i+[q_i(0)-\alpha_i]e^{-\kappa t}\end{aligned}\]

唯一の正規化均衡は q* = α である。どの内点初期価格も、同じ指数率で均衡に近づく。初期価格と α の凸結合になっているため、価格の正値性も直接確認できる。

命題2の条件も確かめられる。コーシー＝シュワルツの不等式から ∑\(\alpha_{i}\)²/\(q_{i}\) ≥ (∑\(\alpha_{i}\))²/∑\(q_{i}\) = 1 なので、

\[q^\ast\cdot Z^S(q)=\sum_i\frac{\alpha_i^2}{q_i}-1\ge 0\]

となり、等号は q = α のときだけ成立する。この例の安定性は、共通の支出比率が作る特別な集計構造に支えられている。Cobb–Douglasという名前だけを理由に、あらゆる保有構造・更新規則・拡張モデルの安定を主張してはいけない。

9. 収束しない例：Scarf型の循環交換

9.1 個人の合理性から循環が生じる

3人、3財の純粋交換経済を考える。各人は一種類の財を1単位持ち、二種類を固定比率で使いたいとする。Scarfの非収束例が示した問題を、次の対称な構成で具体化する。[3]

循環交換を作る初期保有と効用
消費者初期保有効用
A(1,0,0)min(x₁,x₂)
B(0,1,0)min(x₂,x₃)
C(0,0,1)min(x₃,x₁)

A は所得 q₁ を使って財1と財2を q₁/(q₁+q₂) ずつ買う。B、Cも同様である。集計すると、次の超過需要が得られる。

\[\begin{aligned}Z_1^C(q)&=\frac{q_3}{q_1+q_3}-\frac{q_2}{q_1+q_2}\\[4pt]Z_2^C(q)&=\frac{q_1}{q_1+q_2}-\frac{q_3}{q_2+q_3}\\[4pt]Z_3^C(q)&=\frac{q_2}{q_2+q_3}-\frac{q_1}{q_1+q_3}\end{aligned}\]

価格の倍率は各比で相殺され、ワルラスの法則も成立する。正価格で \(Z_1^{C}\) = 0 なら q₂ = q₃ となるため、唯一の正規化内点均衡は q* = (1/3,1/3,1/3) だ。

9.2 主モデルでも保存量があり、周期運動になる

本稿で使う乗法則 \(\dot q_{i}\) = κ\(q_{i}\)\(Z_{i}^{C}\) に対し、次の量を調べる。この保存量の計算は、本稿で明示的に行う導出である。

\[\begin{aligned}H(q)&=\frac1{q_1}+\frac1{q_2}+\frac1{q_3}\ge 9\\[3pt]\dot H&=-\kappa\sum_{i=1}^3\frac{Z_i^C(q)}{q_i}=0\end{aligned}\]

最後の等式は各分数を代入して通分すれば確認できる。たとえば分母 q₁+q₂ を持つ2項は (q₁−q₂)/(q₁q₂) にまとまり、三組を足すとゼロになる。

H は均衡でのみ最小値9を取る。H = h > 9 の集合は、単体の内部にある閉じた滑らかな曲線になる。Hは厳密凸で境界に向かって発散するため、この曲線は均衡を囲み、境界へ逃げない。その曲線上に定常点はない。したがって、均衡以外の内点から出発した軌道は曲線上を回り続け、周期運動になる。

唯一の均衡、合理的な需要、需要超過で値上げする規則がそろっても、価格は均衡へ収束しない。ここで起こるのは、無限大への発散ではなく、保存量に沿った持続的な循環である。

適用範囲：この例では、たとえば q₁ = 0、q₂,q₃ > 0 のとき \(Z_1^{C}\) = 0 となる。原問題の「ゼロ価格なら超過需要が厳密に正」という強い境界条件は満たさない。第11節では、その境界条件まで満たしても収束が保証されない別の構成を示す。

10. 循環から収束へ：同じ経済の連続的な拡張

10.1 二つの消費者群を混ぜる

第8節の共通比率を α = (1/3,1/3,1/3) とし、安定な超過需要 \(Z^{S}\) と循環する超過需要 \(Z^{C}\) を混ぜる。

\[\begin{aligned}Z^\theta(q)&=(1-\theta)Z^C(q)+\theta Z^S(q),\quad 0\le\theta\le1\\[3pt]\dot q_i&=\kappa q_i Z_i^\theta(q)\end{aligned}\]

これは集計関数の形式的な混合にとどまらない。Scarf型の3人に (1−θ)\(e_{i}\)、Cobb–Douglas型の別の3人に θ\(e_{i}\) の保有を与える6人経済として実現できる。\(e_{i}\) は第i財を1単位持つベクトルだ。両群の需要は所得、したがって保有の倍率に比例するため、この \(Z^{\theta}\) が正確に得られる。各財の総保有は引き続き1である。

θ は補完的な固定比率の消費者群と、共通支出比率の消費者群との保有配分比率である。現実の市場への政策処方や、個人の合理性の強弱を表す指標ではない。

10.2 小さな散逸が循環を減衰させる

同じ H = ∑1/\(q_{i}\) を使うと、循環成分はその微分に寄与せず、

\[\dot H=-\kappa\theta\left[\frac13\sum_{i=1}^3q_i^{-2}-H\right]\]

となる。∑\(q_{i}^{-2}\) ≥ H²/3 と H ≥ 9 より、

\[\begin{aligned}\dot H&\le-\kappa\theta\frac{H(H-9)}9\le-\kappa\theta(H-9)\\[4pt]0\le H(q(t))-9&\le[H(q(0))-9]e^{-\kappa\theta t}\end{aligned}\]

を得る。θ > 0 なら H は9へ近づく。Hの劣位集合は内部コンパクトなので解は境界に達せず、Hの唯一の最小点 q* へ収束する。θ = 0 では H が保存され、周期運動が残る。

したがって、この特定の6人経済では、正の比率のCobb–Douglas群を加えるだけで大域収束を証明できる。ただし、これを「どんな市場も少量の別の消費者を加えれば安定する」という一般命題に広げることはできない。

10.3 局所的には減衰する回転になる

均衡での接空間の固有値は、直接微分すると

\[\lambda_\pm=-\kappa\theta\pm i\,\frac{\kappa(1-\theta)\sqrt3}{4}\]

になる。θ = 0 では純粋な回転、0 < θ < 1 では減衰する振動、θ = 1 では指数収束である。ここで H−9 に対する上の大域評価と、価格偏差に対する局所固有値の減衰率は、異なる量の評価として区別する。

11. 三公理をすべて満たしても、価格は循環できる

Scarf型の例に残った境界条件の違いを埋めるため、ここでは抽象的な超過需要場を明示的に構成する。個人の効用からの実現をこの節で主張するものではなく、三つの表示公理だけから収束を導くことができない、という論理的な反例である。

3財の非負価格 p ≠ 0 に対して、次の記号を定める。

\[\begin{aligned}n&=\frac p{\|p\|},\quad c=\frac{(1,1,1)}{\sqrt3},\quad d=c\cdot n\\[3pt]a&=0.9,\quad\varepsilon=0.01\\[3pt]Z(p)&=(a-d)(c-dn)+\varepsilon(c\times n)\end{aligned}\]

× は3次元の外積である。nだけに依存するので0次同次であり、n · (c−dn) = 0、n · (c×n) = 0 からワルラスの法則が成立する。原点を除けば滑らかでもある。

境界 \(n_{i}\) = 0 では d ≤ √(2/3)、|\((c\times n)_i\)| ≤ 1 なので、

\[Z_i(p)\ge\frac{0.9-\sqrt{2/3}}{\sqrt3}-0.01>0.038\]

となり、厳密な内向き条件も満たす。一方、c−dn と c×n は互いに直交し、いずれもノルム √(1−d²) を持つ。ε > 0 なので、正象限の球面上で Z = 0 となるのは n = c だけだ。

単位球面上の加法的な調整 ṅ = Z(n) を採用すると、軸 c に沿った成分 d は

\[\dot d=(a-d)(1-d^2)\]

に従う。d < a なら増加し、a < d < 1 なら減少する。cから出発する場合を除き d → a となるが、cの周囲の方位角は速度 ε で回り続ける。d = a の円は、各座標の最小値が a/√3 − √(2/3)√(1−a²) ≈ 0.164 > 0 なので、全体が正価格領域に収まる。

結論は、滑らかさ、0次同次性、ワルラスの法則、厳密な境界内向き条件、唯一の正規化均衡がそろっても、この調整則には安定な周期軌道が生じるということだ。均衡 c の接空間固有値は (1−a) ± iε であり、均衡自体は不安定である。

前節の循環例は個人の選択まで明示し、この節の反例は原問題の公理をすべて満たす。それぞれ何を反証しているかを分けることで、境界条件を理由に論点がすり替わることを避けられる。

12. 市場にポテンシャルがある場合

12.1 散逸する構造を追加する

主モデルは M(q) = diag(q) − \(qq^{\mathsf T}\) を使って q̇ = κM(q)Z(q) と書ける。Mは対称半正定値で、内点では零空間が1の張る空間になる。ワルラスの法則により \(qq^{\mathsf T}\)Z = 0 だから、元の乗法則と同じである。

もし単体上にポテンシャル Φ があり、Z = −∇Φ + b(q)1 と表せるなら、

\[\begin{aligned}\dot q&=-\kappa M(q)\nabla\Phi(q)\\[3pt]\dot\Phi&=-\kappa\nabla\Phi(q)^{\mathsf T}M(q)\nabla\Phi(q)\le0\end{aligned}\]

となる。Φが単体上で厳密凸、最小点が内点にあり、軌道が内部コンパクト集合に留まるなどの条件があれば、その最小点への収束を導ける。Mの零空間とワルラスの法則から、内点定常点が Z = 0 に一致することも確認できる。

接空間を保つ歪対称行列 R、すなわち \(R^{\mathsf T}\) = −R、R1 = 0 を使い、q̇ = −(κM+R)∇Φ としても、RはΦの時間微分に寄与しない。これは減衰と回転を分離する一つの形式だ。ただし正値性・境界不変性は別途必要であり、すべての市場にそのようなΦが存在するわけではない。

微分可能な場が局所的に勾配になるには、適切な座標で交差微分の対称性が必要になる。一般の集計超過需要には所得効果があり、その対称性は自動的には得られない。凸ポテンシャルを持つ市場は、特別な構造を持つ市場クラスとして研究されている。[6]

12.2 Fisher市場を交換経済と混同しない

Fisher市場では、買い手の貨幣予算 \(b_{a}\) と売り手の供給 \(s_{i}\) が外生的に固定される。一般の交換経済の所得 p · \(\omega_{a}\) とは異なる。全予算 B = ∑\(b_{a}\) が使われると、

\[p\cdot Z(p)=B-p\cdot s\]

であり、財だけの超過需要に p · Z = 0 は恒等的には成立しない。予算が名目尺度を固定するため、価格を一律に変えても同じモデルには戻らない。

買い手がCobb–Douglas効用を持つFisher市場なら、\(\beta_{i}\) = \(\sum_{a}\)\(b_{a}\)\(\alpha_{ai}\) として \(Z_{i}\)(p) = \(\beta_{i}\)/\(p_{i}\) − \(s_{i}\) となる。ここには明示的な凸ポテンシャルがある。

\[\begin{aligned}\Phi(p)&=\sum_i s_i p_i-\sum_i\beta_i\log p_i,\quad\nabla\Phi=-Z\\[3pt]\dot p_i&=\kappa p_iZ_i=\kappa(\beta_i-s_ip_i)\\[3pt]p_i^\ast&=\frac{\beta_i}{s_i}\qquad(\beta_i,s_i>0)\end{aligned}\]

この例では各価格が指数収束する。しかし、Fisher市場で得た凸性を、所得が価格に依存する交換経済全体へ無条件に移すことはできない。

12.3 均衡を計算するアルゴリズムと市場の行動

独立な価格座標に移したニュートン型の方法は、超過需要とそのヤコビ行列を使って根を探せる。だが、全市場の微分情報を誰が持ち、誰が更新を実行するかは別問題になる。価格機構の情報要件はSaariとSimonの研究でも検討されている。[13]

また、単に ‖Z‖²/2 を最小化すれば十分とも限らない。その勾配がゼロになる条件は \(J^{\mathsf T}\)Z = 0 であり、Z = 0 と一致しない停留点を持ちうる。残差の小ささと、最適化アルゴリズムが止まったという事実は分けて確認する。

13. 離散更新、観測遅延、ノイズ

13.1 連続時間で安定でも、刻みが大きいと不安定になる

局所系 v̇ = Av を陽的Euler法で離散化すると、\(v_{k+1}\) = (I+hA)\(v_{k}\) となる。離散系の収束条件は、すべての固有値λについて |1+hλ| < 1 である。

\[\begin{aligned}\lambda=-a,\ a>0\quad&\Longrightarrow\quad0<ha<2\\[3pt]\lambda=\alpha+i\beta,\ \alpha<0\quad&\Longrightarrow\quad0<h<\frac{-2\alpha}{\alpha^2+\beta^2}\end{aligned}\]

hが実際の価格改定間隔なら経済モデルの条件であり、微分方程式を計算する刻みなら数値手法の条件である。この二つを混ぜると、計算上の発散を市場の不安定性と誤認する。

特に純虚数λ = iβにEuler法を使うと、|1+ihβ| > 1 となり、どれほど小さな正のhでも線形化した軌道が人工的に膨らむ。循環例を検証するときは、保存量の誤差と刻みを半分にした結果を併せて調べる。

13.2 正値性を守る離散更新

価格を指数で更新して正規化する規則も使える。

\[q_{i,k+1}=\frac{q_{i,k}\exp\left(h\kappa Z_i(q_k)\right)}{\sum_j q_{j,k}\exp\left(h\kappa Z_j(q_k)\right)}\]

正の初期値なら常に正で、和も1になる。h → 0で主モデルに一致するが、有限のhで同じ保存量や収束性を持つとは限らない。正値性を守ることと、安定性を守ることは異なる。

13.3 反応が速すぎると、遅れが振動を生む

単一モードの遅延負帰還 v̇(t) = −a v(t−τ)、a > 0 を考える。τは需要を観測して価格へ反映するまでの遅れだ。特性方程式は λ+a \(e^{-\lambda\tau}\) = 0 となる。λ = iωを代入すると、最初の安定境界は ω = a、aτ = π/2 に現れる。このスカラー系の漸近安定条件は

\[a\tau<\frac\pi2\]

である。[12] 反応係数aを大きくするほど、許される遅延τは小さくなる。したがって「需要超過にはできるだけ速く反応するほどよい」という結論は一般には成り立たない。多財系の閾値は行列と遅延構造に依存する。また線形安定性を失ったことだけから、非線形の安定周期軌道の存在までは結論できない。

13.4 ノイズのある経済では点への収束が目的とは限らない

局所モデルを dv = Av dt + Σ \(dW_{t}\) とし、Aのすべての固有値の実部が負なら、一定の外乱の下では平均が均衡へ近づいても分散は一般にゼロにならない。定常共分散Cは AC+\(CA^{\mathsf T}\)+Σ\(\Sigma^{\mathsf T}\) = 0 を満たす。これは均衡の周囲の線形近似であり、価格の正値性を大域的に保証する確率モデルではない。

単一モード dv = −av dt + σ \(dW_{t}\) なら定常分散は σ²/(2a) であり、固定された外乱に対してaを大きくすると分散は減る。一方、観測ノイズを更新係数a倍して取り込むモデルではノイズ係数がaσとなり、定常分散はaσ²/2に増える。反応速度とノイズの関係は、ノイズがどこへ入るかに依存する。

技術や嗜好が動くなら、均衡自体も動く。外乱のないスカラー局所モデルで均衡の移動速度が高々v、復元係数がaなら、誤差方程式 ė = −ae−q̇* から lim \(\sup_{t\to\infty}\)|e(t)| ≤ v/a を得る。ただし観測遅延があれば、反応速度を上げるほど安定性を保てる遅延の上限は小さくなる。追従速度、遅延、ノイズの入り方を併せて調べることも、価格力学の役割になる。

14. 非均衡のまま取引する経済へ拡張する

価格の提示だけを繰り返す模索過程では、均衡に達するまで初期保有を固定できる。実際に売買すれば財と資金の分布が変わるため、同じ固定関数 Z(p) を追い続けるモデルでは足りない。以下はその違いを明示する会計的な構成例であり、普遍的な収束定理ではない。

状態・注文・約定を分ける

主体を a、財を i、離散的な期を t とする。状態は名目価格 \(P_{i,t}\)、保有・在庫 \(I_{ai,t}\)、現金 \(m_{a,t}\)、期待 \(e_{a,t}\) からなる。価格の単位は「通貨／財の単位」、現金は通貨、在庫は各財の物量である。期内の順序を生産、注文、約定、消費、状態更新と固定する。以下の生産・取引・消費は、その期に動く数量を表す。

純産出 \(y_{ai,t}\) には投入財を表す負の値も許し、技術集合と \(I_{a,t}\)＋\(y_{a,t}\) ≥ 0 を満たすものを選ぶ。出品 o と購入希望 d には、財と資金の制約を課す。

\[\begin{aligned}0\le o_{ai,t}&\le I_{ai,t}+y_{ai,t},\quad d_{ai,t}\ge0\\[2pt]\sum_i P_{i,t}d_{ai,t}&\le m_{a,t}\end{aligned}\]

この予算制約は「期首現金だけで購入する」という追加仮定である。同じ期の売上を使う仕組みや信用を導入するなら、決済順序と債権・債務を別に定める。取引後の財を同じ期に再販売しないことも、ここでは明示的に仮定する。

\(v_{ab,i,t}\) ≥ 0 を主体 a から b への実現取引量とする。希望数量がそのまま実現するとは限らない。

\[\begin{aligned}\sum_b v_{ab,i,t}&\le o_{ai,t},\quad \sum_a v_{ab,i,t}\le d_{bi,t}\\v_{aa,i,t}&=0\end{aligned}\]

この制約を満たす約定の選び方まで指定する。比例配給、先着順、注文板などは異なる動学を生む。配給規則を空欄のままにして「需要＝販売量」と置けば、欠品時の行動を説明できない。

物量と現金の保存

消費 \(c_{ai,t}\) ≥ 0 は次期在庫が非負となる範囲で選ぶ。純移転 \(\tau_{a,t}\) は移転後も現金が非負となる範囲に限定する。更新式は次になる。

\[I_{ai,t+1}=I_{ai,t}+y_{ai,t}+\sum_b v_{ba,i,t}-\sum_b v_{ab,i,t}-c_{ai,t}\]
\[m_{a,t+1}=m_{a,t}+\sum_{b,i}P_{i,t}v_{ab,i,t}-\sum_{b,i}P_{i,t}v_{ba,i,t}+\tau_{a,t}\]

全主体について足すと取引項が相殺される。

\[\begin{aligned}\sum_a\Delta I_{ai,t}&=\sum_a y_{ai,t}-\sum_a c_{ai,t}\\\Delta M_t&=\sum_a\tau_{a,t},\qquad M_t=\sum_a m_{a,t}\end{aligned}\]

外部との貨幣の注入・回収がない閉じた現金系では、純移転の合計はゼロになる。賃金・配当も支払い側と受け取り側を対応させる。貨幣保有の需要があるため、財だけの注文超過に純粋交換経済のワルラス法則を機械的に適用してはいけない。

行動規則を指定して初めて閉じる

生産、注文、消費を現在の状態と期待の関数として定め、約定、期待更新、移転、価格改定の規則を指定すれば、状態遷移が閉じる。例えば期待販売量を \(e_{t+1}\)＝(1−γ)\(e_{t}\)＋γ\(v_{t}\)、0 ≤ γ ≤ 1 で更新できる。ただし欠品で販売が制限されると、この学習は潜在需要を過小評価する。未充足注文の観測を加えるかどうかが結果を変える。

価格改定の候補として、無次元の注文超過 \(E_{i,t}\) と在庫偏差を使える。

\[\log\frac{P_{i,t+1}}{P_{i,t}}=\kappa_i E_{i,t}-\eta_i\frac{I_{i,t}-I_i^\ast}{\bar I_i},\quad\kappa_i,\eta_i>0\]

ここで \(I_{i,t}\) は売り手側の集計在庫、\(I_{i}^{*}\) は目標在庫、\(\bar I_{i}\) > 0 は物量の基準値である。E も注文量と出品量の差を所定の物量で割って定義する。この式は正価格を保つが、売り手の利潤最大化から自動的に導かれるものではない。誰が何を観測して価格を変えるのかを指定する追加的な行動仮説である。

また、注文超過と在庫偏差が相殺すれば価格だけが止まる場合もある。会計的一貫性、定常点と競争均衡の一致、そこへの収束は別々に示す必要がある。非均衡で取引した経路によって保有分布が変われば、到達する均衡も初期保有を固定した場合と異なり得る。

Cole・Fleischer・Rastogiは、有限在庫を持つ反復フィッシャー市場の特定のクラスで、局所情報による非同期更新の収束を示した。ただし供給と買い手予算を各期に外生的に与えるモデルであり、一般の貨幣循環まで自動的に説明する結果ではない。[8]

15. 相対価格の調整と貨幣的な名目基準

純粋交換経済の価格正規化は、通貨建ての物価水準を決めない。フリードマンの観点を組み込むには、個別財の相対価格と、経済全体の名目尺度を分けてモデル化する。

固定ウェイト \(\omega_{i}\) > 0、∑\(\omega_{i}\)＝1 と基準価格を用いて、無次元の幾何平均物価指数 Π を定義する。

\[\begin{aligned}\Pi&=\exp\left[\sum_i\omega_i\log\left(\frac{P_i}{P_{i,0}}\right)\right]\\r_i&=\frac{P_i}{\Pi},\qquad P_i=\Pi r_i\end{aligned}\]

\(r_{i}\) は基準時点の通貨単位で測った価格で、価格比 \(r_{i}\)/\(r_{j}\) は名目価格比と一致する。連続時間で補間すれば、個別価格の変化は一般物価の変化 π＝d log Π/dt と、d log \(r_{i}\)/dt に分解される。この指数は説明用の定義であり、特定の公的物価指数と同一ではない。

対象範囲を指定した名目支出率を \(E^{\mathrm{nom}}\) とし、Y = \(E^{\mathrm{nom}}\)/Π を、この指数でデフレートした実質支出率と定義する。任意の幾何平均指数によるデフレートは、固定基準価格と数量の積を足した値と常に一致するわけではない。M は貨幣残高、V = \(E^{\mathrm{nom}}\)/M はその支出に対応する流通速度とする。最終支出を対象にする場合は、中間財を含む全約定額をそのまま代入しない。

\[MV=\Pi Y,\qquad\pi=\mu+\nu-g\]

ここで μ＝d log M/dt、ν＝d log V/dt、g＝d log Y/dt。V＝ΠY/M と定義するだけなら数量方程式は恒等式である。因果的な貨幣数量説には、貨幣需要、供給、実質産出の決定について追加仮説が要る。安定した貨幣需要という仮説も、流通速度が常に一定という仮説とは異なる。

純粋交換モデルの Z(λp) = Z(p) は、価格表示の尺度対称性である。それだけから、現実の貨幣供給を変えても実質量が即座に不変になるという貨幣中立性は導けない。

フリードマン的な構成では、長期の実質的制約を資源・技術・制度に置き、貨幣増加だけで実質産出や雇用を任意の水準へ恒久的に引き上げられるとはしない。一方、予想の調整や契約の時間差を通じた短期の実質効果は認める。本人も、貨幣が実質変数に重要な影響を持つことと、実質量を任意の水準へ固定できないことを区別している。[11]

特定財の供給減少は相対価格を変え、実質産出や測定される物価水準にも影響し得る。しかし一回の水準変化と持続的な一般物価上昇は同じではない。持続インフレは貨幣成長、貨幣需要、実質成長の関係として扱う。相対価格の力学を証明するだけでインフレ理論は完成せず、数量方程式だけで多市場の収束も保証されない。

フリードマンが重視した安定した貨幣的背景は、価格・賃金の調整を嗜好や技術の変化に必要な相対価格の変化へ向けるための条件として位置づけられる。これは、あらゆる市場が無条件に安定するという命題ではない。[11]

16. 既存研究はどこまで進んだか

スメールの第8問題は、一般均衡理論へ価格調整の時間発展を組み込み、できれば個々の経済主体の行動からその過程を説明するという研究課題である。原文が「限定された状況でのみ解かれている」と述べたのは1998年のことであり、その文章を現在の研究状況へそのまま移してはいけない。単に微分方程式を書くこと、均衡へ収束する計算過程を作ること、実際の市場行動を説明することは、それぞれ達成すべき内容が異なる。[1]

三つの障壁は、異なる命題である

アロー＝ドブリューの存在定理は、所定の選好・技術・資源条件を満たす経済に競争均衡が存在することを保証する。均衡の存在から、特定の価格調整則の安定性が直ちに従うわけではない。静的な均衡条件と動学の収束条件を分けることが出発点になる。[2]

スカーフの反例は、特定の調整過程の非収束を示す。個人の効用最大化から作った経済でも、自財の超過需要に応じて価格を変える過程が、均衡の周囲を振動し続ける例がある。「不安定」という表現には、均衡へ近づかない循環も含まれ、常に価格が無限大へ発散するという意味ではない。別の情報や更新則を採用するすべての機構まで否定した結果でもない。[3]

ゾンネンシャイン＝マンテル＝ドブリューの結果は、集計の形状制約の弱さを示す。正価格領域の適切なコンパクト集合上では、連続性・斉次性・ワルラス法則などに整合する非常に広い形の超過需要が、個人の合理的選択の集計として実現できる。したがって、個人の合理性だけを根拠に市場全体の一意性や安定性を保証できない。これは均衡の不存在や、市場の必然的な不安定性を意味しない。[4]

サーリ＝サイモンの研究は、収束機構が要求する情報を問う。ニュートン法に類似する過程では、超過需要とその価格への反応について広範な情報を使う。彼らは、扱う機構のクラスでその情報要求を大幅に減らすことの限界を検討した。「いかなる市場も無限の情報なしには収束できない」と一般化する根拠にはならない。利用可能な観測、履歴、補助状態、対象経済の制約を指定して読む必要がある。[13]

フィッシャー市場で進む、条件を明示した収束理論

固定された貨幣予算を持つ買い手と所与の供給を扱うフィッシャー市場では、凸最適化との対応が有力になる。Cheung・Cole・Devanur（2013）は凸ポテンシャルを持つ市場を研究し、レオンチェフ効用や補完的CES効用を持つフィッシャー市場について離散的価格調整の収束を示した。補完財の存在だけで非収束と結論することはできず、この構造を一般の初期保有交換経済へ無条件に移すこともできない。[6]

Cheung・Cole（2018）はCESまたはレオンチェフ効用のフィッシャー市場で、特定の非同期価格調整を解析した。更新が同時でなくても収束を証明できるが、任意の遅延や更新幅が許されるという結果ではない。[7]

Goktas・Zhao・Greenwaldの2025年改訂版は、ヒックス需要の価格弾力性が有界なホモセティック・フィッシャー市場で収束率を与える。弾力性が発散する線形効用の限界を、その有界性の定理へ含めてはいけない。[9]

Nan・Gao・Kroerの2025年改訂版は、線形フィッシャー市場の価格調整を双対問題の劣勾配法として解析した。十分小さい固定刻み幅についての保証は、刻み幅に依存する半径の均衡近傍への収束であり、固定刻み幅のまま厳密な均衡点へ収束するという主張ではない。[10]

以上の到達点から、本稿の仕事は新しい普遍解の宣言ではなく、既存の定理と具体的なモデルを接続し、どの仮定がどの結論を支えるかを示すことになる。数学的収束、分散的実装、現実への説明力をそれぞれ確かめる必要がある。

17. 理論を観測によって検証する

価格だけを観測していても、どの調整機構が働いたかは決まらない。注文量、約定量、未充足注文、欠品、在庫、価格変更の時刻を区別して記録する。販売量は在庫制約によって打ち切られ得るため、そのまま需要量とはみなせない。

例えば上の価格規則を推計する場合、注文超過に対する係数が正か、過剰在庫に対する係数が負か、他市場の価格を加えると説明が改善するかを調べる。ただし同時点の価格と需要は相互に決まる。単純な回帰係数を価格の因果効果と呼ばず、観測順序、外生変化、操作変数など、採用した識別の根拠を明示する。

検証の中心は、推計に使わなかった期間に、価格・数量・在庫の調整経路を予測できるかである。収束を主張するモデルなら、外的な条件が概ね一定な期間に、不均衡が長期的にゼロへ近づくか、予測した減衰速度や振動が観測されるかを確かめる。収束していても残差が毎時点単調に減るとは限らず、単調性の検証はその性質を予測するLyapunov関数などについて行う。外部条件が動き続ける経済では、固定点への収束と、動く均衡への追随を区別する。

予測と合わなければ、需要関数、価格決定規則、情報遅延、取引制約のどこが破れたかを調べる。観測された変動をすべて未知のショックへ押し込むと、モデルは反証できなくなる。数学的に正しい定理であっても、その仮定が現実に対応するかは別の検証課題である。

    if any(x <= 0 or not isfinite(x) for x in q):
        raise ValueError("Non-positive price; reduce the step size")
    x, y, z = q
    excess = (
        z / (x + z) - y / (x + y),
        x / (x + y) - z / (y + z),
        y / (y + z) - x / (x + z),
    )
    return [kappa * ((1 - theta) * q[i] * excess[i]
                    + theta * (1 / 3 - q[i])) for i in range(3)]

        q = rk4(q, dt, theta)
    return q, sum(1 / x for x in q)

for theta in (0.0, 0.02, 0.2, 1.0):
    coarse, H = run(theta)
    fine, _ = run(theta, step=0.005)
    difference = max(abs(a - b) for a, b in zip(coarse, fine))
    print(theta, coarse, "H =", H, "step difference =", difference)
